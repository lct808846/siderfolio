# N 体数值实验准备研究步骤

本技能用于规范小规模孤立牛顿 N 体数值模拟的参数设计与审阅流程，所有计算必须由用户在模拟卡片确认后交由独立计算 Worker 执行。

## 1. 参数与物理假设核对

1. 确认粒子数处于当前受控范围（2–128 粒子），固定采用标准单位：质量 `M_sun`、位置 `AU`、速度 `AU/yr`、时长 `yr`（引力常数 `G = 4π²`）。
2. 根据体系特征与用户指定选择积分引擎：少体、行星或双星系统默认 `rebound`，多体星团或近距离交会场景可选 `petar`。
3. 合理设置质心静止系，确保粒子 ID 唯一且初始两两间距 `> 1e-5 AU`，时间跨度与采样点数兼顾轨道分辨率与计算预算。

## 2. 生成可审阅参数草案

1. 调用 `prepare_nbody_simulation` 输出完整参数方案，清晰列出粒子质量/初位置/初速度、单位、引擎、采样点数与孤立点质量物理假设（不宣称包含银河系潮汐场、气体阻尼、相对论修正或恒星演化）。
2. 绝不编造未执行的轨道演化或能量/角动量守恒诊断结果；提示用户在模拟卡片中核对或微调参数后点击确认提交，完成后在右侧结果栏查看轨迹图与守恒诊断。
