# Siderfolio UI 设计规范

规范版本：3.0 · 更新日期：2026-11-22 · 适用于所有新增、修改的前端界面。

本文是跨版本维护的界面设计基准，覆盖查询与绘图工作台、科研项目空间、来源关联、科研流程、N 体模拟、本地知识库、文献问答、本机设置、个人资料、账号安全和管理控制台。设计目标是让科研工作台既具备专业天文观测台的克制、精准与可信度，又拥有清晰、轻盈、富有层次的现代空间美学。

**执行约定：**“必须”是开发与审查要求；“建议”允许按任务调整；“既有例外”仅适用于指定区域。本文规定目标，不表示现有页面全部符合或已通过视觉验收。

## 1. 设计方向与美学原则（3.0 物理光影与精致度升级）

- **结构化替代文本堆砌**：避免长段无层级纯文本与点号拼接的长元数据串。优先以**结构化卡片（Card）**承接独立任务块、以**语义胶囊（Capsule / Pill）**表达状态/来源/物理量标签、以**指标瓦片（KPI Tile）**突出核心统计与进度、以**分段胶囊控件（Segmented Control）**组织视图与模式切换。
- **物理光影与发丝级微边框**：放弃生硬实线框与纯黑/纯白高反差底色；全部 6 套主题统一采用发丝级半透明边框（浅色 `rgba(..., 0.08)` / 深色 `rgba(255,255,255,0.08)`）、顶部 `1px` 物理内高光（`--specular-top` / `--specular-sheen`）、大半径低透明度多层扩散阴影（`--shadow-card` / `--shadow-float`）及暗夜微差中性色阶梯（`#090d11 → #10161c → #151d24 → #1b242d`），用明度与微光建立空间纵深。
- **克制的毛玻璃分层**：真实毛玻璃（`backdrop-filter: blur(20–22px) saturate(155%)`）仅用于真正产生空间遮挡的悬浮层——顶部导航栏、侧栏、悬浮输入舱、下拉弹出菜单与模态弹窗；底层阅读卡片、表格与文献正文保持清晰锐利表面，不滥用全屏模糊，并完整遵守「关闭毛玻璃」与系统降低透明度设置。
- **三层灰度信息秩序与同心圆角几何**：通过 `--ink`（92–95%）→ `--muted`（62–72%）→ `--ink-tertiary`（44–46%）建立柔和清晰的对比层级；大标题收紧字距（`-0.025em`）与行高（`1.28`），数据与统计值全面启用 `tabular-nums`；圆角与间距严格落在 4px/8px 网格并遵循嵌套同心法则（`R_outer = R_inner + padding`，例如弹出菜单 `14px = 8px + 6px`、输入舱 `20px = 8px + 12px`）。
- **物理阻尼微交互**：统一采用 `cubic-bezier(0.16, 1, 0.3, 1)`（160–200ms），交互卡片悬停以边框微提亮 + 极淡蒙版（`--hover-veil`）反馈，按钮与卡片按压给予 `scale(0.98–0.99)` 实体按键触感，会话加载采用定向微光骨架屏，滚动条统一为 8px 极细半透明样式。
- **克制、可读、科学诚实**：卡片与胶囊用于降低信息扫描成本，而非纯装饰；禁止卡片无节制多层套娃（除列表项与指标瓦片外，内容区最多“外层工作区面板 + 一层内容分组卡片”），禁止干扰科学图表阅读的强饱和色块。
- **页面主骨架统一**：统一为“深色导航 → 当前面板标题与操作 → 核心交互/卡片内容 → 证据/结果核查”。不同科研任务按信息密度采用 2 栏或 3 栏，共用同一套组件语法与视觉语言。
- **聚焦科研信息**：不把服务器内部配置或原始调试堆栈塞入普通主流程；原始 JSON、完整 ADQL、SHA-256 与运行环境信息统一收纳在折叠区或详情抽屉内按需核对。

规则发生冲突时，先遵守任务明确要求和安全、数据语义约束，再遵守本文。样式最终生效的值必须通过实际层叠核对，不能只读取某个文件的第一条规则。

## 2. 统一来源与职责

| 内容 | 当前维护入口 | 使用约定 |
| --- | --- | --- |

### 3.3 多主题与用户外观偏好体系（2.1 新增）

为满足日间星表分析、长时间论文阅读与夜间观测暗适应等科研场景，在设置页提供独立「外观与主题」分类（对所有已登录用户可见），由 `frontend/src/stores/appearance.ts` 集中管理并在应用挂载前通过 `<html>` 数据属性即时生效，偏好仅保存在当前浏览器本机存储中，不上传服务端：

- **6 套内置科研主题（`data-theme` / `data-theme-mode`）**：
  - 日间主题：`emerald`（天文台翠绿，默认）、`celestial`（靛蓝星海）、`parchment`（暖纸典籍，低蓝光护眼）、`nebula`（星云暮紫）。
  - 暗夜主题：`obsidian`（暗夜深空，深蓝黑底 + 星光翠绿强调）、`dome`（观测圆顶红光，深炭底 + 暗红护眼强调）。
  - 支持「跟随操作系统自动切换明暗」，可在用户指定的日间主题与暗夜主题之间自动配对切换。
- **外观定制维度**：
  - 界面密度（`data-density`）：`compact`（紧凑）/ `comfortable`（标准）/ `spacious`（舒展）。
  - 阅读字号缩放（`data-font-scale`）：`sm`（92%）/ `md`（100%）/ `lg`（108%）/ `xl`（115%）。
  - 边角风格（`data-radius`）：`sharp`（利落）/ `rounded`（圆润，默认）/ `soft`（柔和）。
  - 正文阅读列宽（`data-reading-width`）：`narrow`（760px）/ `standard`（880px）/ `wide`（1120px）。
  - 长文阅读字体（`data-reading-font`）：`sans`（本地无衬线）/ `serif`（本地学术衬线，不引入外部网络字体）。
  - 质感与性能开关（全部独立可控，且提供「一键性能模式 / 恢复全部视觉质感」快捷切换）：`data-astro-backdrop`（天文背景矢量层开/关）、`data-astro-motion`（背景动态效果开/关并释放 `will-change`）、`data-ambient`（多点径向渐变背景氛围开/关）、`data-glass`（全局 `backdrop-filter` 毛玻璃实时模糊开/关）、`data-shadows`（多层扩散阴影与物理内高光开/关）、`data-motion`（应用内减弱动效开关，与系统 `prefers-reduced-motion` 并行生效）。
- 所有新增界面组件必须使用语义变量（`--paper`、`--surface-card`、`--surface-elevated`、`--ink`、`--muted`、`--line`、`--accent`、`--topbar-*` 等），禁止硬编码纯白背景或浅色文字，确保在 6 套日/暗夜主题下均保持清晰可读。

补充要求：
- “成功”必须有明确完成文案；普通选中态不等于执行成功。
- 状态必须同时通过文字或图标表达，不能仅依赖颜色。
- 科学图表按数据类别、数值范围和科学语义配色，不强制套用界面绿色。

## 4. 字体与信息层级

| 场景 | 字体 / 字号 | 行高与约束 |
| --- | --- | --- |
| 普通正文、表单值 | `--font-ui`，14px | 约 1.65；常规字重 400 |
| 回答、长篇证据与用户消息 | `--font-ui`，14px | 1.9–1.95；保留段落与引用层级 |
| 面板主标题 | `--font-ui`，15.5–17px / 600 | 1.4–1.5；简洁单行或自然换行 |
| 卡片标题 / 章节标题 | `--font-ui`，15–18px / 600 | 明确层级，不大于页面主标题 |
| 指标瓦片主数值 | `--font-ui`，18–22px / 650 | 启用 `tabular-nums`，单位清晰 |
| 表单标签、按钮文字 | `--font-ui`，13px / 500 | 动作明确，不使用全大写装饰 |
| 胶囊标签、徽标、表头 | `--font-ui`，11.5–12px / 550 | 清晰易读，不承载大段正文 |
| 低优先级元数据 | 11px | 仅用于时间、修订号、字节数等辅助项 |
| 空白起始页标题 | `--font-editorial`，24–30px | 每个起始区最多一处 |
| 代码、编号、原始数值 | `--font-mono`，12px | `source_id`、bibcode、SHA-256、坐标与科学计数法 |

必须使用 `typography.css` 的本地字体及回退链，不引入远程字体服务。长项目名、邮箱、文件名、引用 ID 必须有换行或省略策略；科学计数法、负号、上下标、单位和有效数字不因排版被改写；缺失值显示 `—`。

## 5. 间距、圆角、阴影与卡片层次（2.0 升级）

| 项目 | 基准 |
| --- | --- |
| 通用间距阶梯 | `--space-1` 至 `--space-6`：4 / 8 / 12 / 16 / 24 / 32px |
| 工作区外框与面板间距 | `--workspace-padding`、`--workspace-gap`：10px；≤680px 为 6px |
| 内容区内边距 | `--pane-padding`：`clamp(20px, 2.4vw, 32px)`；≤680px 为上下 20px、左右 16px |
| 控件圆角 | `--radius-control`：8px（遵循 4px 网格与同心嵌套） |
| 内容卡片圆角 | `--radius-card`：12px |
| 主面板圆角 | `--radius-surface`：16px（弹出菜单 `calc(var(--radius-control) + 6px)` = 14px，形成严格同心弧） |
| 对话框圆角 | `--radius-dialog`：20px（输入舱内边距 12px + 8px 控件 = 20px 同心弧） |
| 胶囊圆角 | `--radius-pill`：999px |
| 卡片与悬浮光影 | `--shadow-card`（静态扩散轻影 + 顶部 1px 内高光）、`--shadow-card-hover` 与 `--shadow-float`（悬浮菜单/弹窗深层漫射影） |
| 工作区表面阴影 | `--glass-shadow`（外层工作区面板共用） |

层次约束：
- 采用“外层工作区面板 → 单层结构化卡片 → 内部轻量瓦片/胶囊/表格”的清晰结构；禁止多层重阴影卡片套娃。
- 半透明与模糊仅用于侧栏、顶部导航与模态遮罩；正文、数据表与文献原文保持稳定不透明底色。

| `.ui-step-rail` / `.ui-step-pill` | 横向流程阶段胶囊条，用于引导式空状态与多步骤流程说明 |

| `.ui-empty-card` / `.ui-empty-inline` | `.ui-empty-card` 仅用于独立工作区空白画布（带居中图标徽章、说明与主操作）；卡片（`.settings-group` / `.ui-card`）与弹窗（`<dialog>`）内部严禁再嵌套带边框阴影的空状态卡片，统一使用扁平无框无阴影的 `.ui-empty-inline` |

## 7. 页面骨架与响应式

常规工作区复用 `WorkspaceHeader`、`WorkspacePaneHeader` 与 `WorkspaceSpaceBar`。顶部主行桌面最小高度 54px、面板标题栏最小高度 56px。

| 视口条件（CSS px） | 设计行为 |
| --- | --- |
| ≥1440px | 查询工作台与项目空间展示三栏（侧栏 + 主区 + 结果核查栏） |
| 1201–1439px | 知识库、文献问答、科研流程、来源关联与项目空间三栏并排；查询工作台按需展开结果抽屉 |
| 981–1200px | 查询工作台与项目空间保持侧栏 + 主区，结果栏右侧展开；多面板子页通过分段胶囊 `PanelSwitcher` 切换并在默认页显示 `.compact-space-bar` |
| ≤980px | 查询工作台与项目空间切换为单列面板视图 |
| ≤680px | 移动端密度；卡片内边距收紧，指标网格与选择卡片自动缩减为 1–2 列，全页无横向溢出 |

## 8. 通用组件契约

| 组件 | 必须统一的行为与外观 |
| --- | --- |
| 主按钮 | `.button-primary` / `.plot-primary`；最小高度 36px、9px 圆角、微立体翠绿渐变；文案用“动作 + 对象” |
| 次要按钮 | 浅色渐变卡片感按钮、1px 边框；悬停柔和变色，不与主按钮争夺视觉焦点 |
| 危险按钮 | `.button-danger`；红色边框与文字，仅用于删除/解除/不可逆操作 |
| 胶囊标签 | `.tag` 与 `.ui-pill` 统一采用 999px 圆角；非交互胶囊不得伪装成按钮 |
| 分段切换器 | 统一使用 `.ui-segmented` 视觉语言（含 `ResultPanel`、`PanelSwitcher`、`WorkspaceSpaceBar`、`LocalAssistant`） |
| 输入 / 选择 | 输入框最小高度 40px、9px 圆角、聚焦光环；保留真实标签，不以占位符替代标签。**禁止使用浏览器原生 `<select>` 下拉框**，所有下拉选择统一复用 `UiSelect` 组件（`popover="manual"` 毛玻璃浮层，支持键盘导航与亮/暗主题，可覆盖原生 `<dialog>`） |
| 数据表 | 圆角外框、柔和表头、行悬停反馈、数值列 `tabular-nums`，支持独立横向滚动 |
| 提示条 | 静态说明与状态提示 `.notice` 采用圆角全边框 + 左侧 3px 语义色条；**所有操作与读取错误提示统一使用 `StatusNotice` 顶部浮层弹窗（`popover="manual"`，与 `SuccessToast` 同源居中顶层展示，可覆盖在原生 `<dialog>` 之上，支持关闭、悬停暂停与多条自动堆叠）**，禁止将操作错误塞入正文或弹窗表单内部挤占布局（历史会话/运行记录的持久化失败详情除外） |
| 刷新行为 | **禁止在任何页面、卡片或弹窗中设置单独的「刷新」按钮**；数据应在进入页面、打开弹窗、切换筛选或完成写操作后自动同步更新 |
| 对话框 | 原生 `dialog`、18px 圆角、吸顶标题与吸底操作区（长表单如新建项目居中独立滚动），取消在前、确认在后 |
| 空状态 | 独立工作区空白画布使用 `.ui-empty-card`；卡片（`.settings-group` / `.ui-card`）、抽屉与 `<dialog>` 弹窗内部禁止套娃边框/阴影/虚线空框，统一使用扁平的 `.ui-empty-inline`，说明原因并给出明确可执行的下一步 |

不要为美观改变任务安全行为：绘图外发确认与脚本审阅、文献发送预览与确认、科研流程先保存后确认执行、导入只读标记均必须完整保留。

## 9. 科研内容与可访问性规则

- 数据结果、原始文献证据、模型解释与用户备注必须通过清晰卡片边界与语义胶囊加以区分，不能混作一团。
- 文献证据保留来源、版本、页码或行号、引用 ID 与打开原文入口；Gaia 位置候选源不标作已确认星团成员。
- 科学图像保持原始纵横比，不裁切坐标轴与色标；放大与下载入口一致。
- 普通文字对比度目标 ≥ 4.5:1，大字号与可交互边界 ≥ 3:1；所有交互卡片与胶囊均为真实 `button` / `a` / `label`，支持键盘焦点（2px 外框、3px 偏移）及 `aria-pressed` / `aria-current` / `aria-selected`。
- 过渡动效克制在 150–200ms，全面遵守 `prefers-reduced-motion`。
- **全局简约天文背景**：工作台全局挂载主题自适应的简约天文矢量背景层（`AstroBackdrop.vue`），各套主题独立定义轨道主色、星光副色、微光层次与半透明面板底色；在「设置 → 外观与主题」中提供「天文背景元素」与「背景动态效果」开关，开启「减少界面动效」或系统减弱动态时自动静止。
