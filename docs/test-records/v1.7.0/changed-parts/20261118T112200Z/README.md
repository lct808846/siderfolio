# AstroAgent V1.7 计算任务增量验收

本轮以 `v1.6.0`（`be0e18ba82db827d37e1a64bbdbe986bf64f6598`）为基线，验证本地工作区的 `1.7.0-dev.0` 镜像。当前源码和实际测试镜像的对应关系见 [SHA-256 清单](tested-images-and-source.json)。浏览器与 API 验收使用 `127.0.0.1:5287` 上的独立容器、合成账号、独立数据库和交接卷。

| 验收项 | 结果 |
| --- | --- |
| Python、契约和构建 | Ruff 与格式通过，OpenAPI 和 TypeScript 生成类型一致，离线专项 46 项通过。Docker 后端、前端与计算 Worker 均构建成功。 |
| PostgreSQL | 38 项通过，覆盖真实身份、任务确认幂等、排队配额、并发认领、取消与成功竞争、租约失效、迟到结果拒绝和项目移除。模型草稿通过合成响应验收，核对缺参提示、参数校验及生成草稿不自动排队。 |
| 浏览器 | 前端单元 40 项，工作台、固定流程、下载和绘图回归 20 项，计算页面双浏览器 2 项通过。计算页面覆盖工作台交接、模板、保存与关闭确认、同页确认、刷新恢复、下载、重跑比较和 390 px 窄屏。 |
| 数值与产物 | REBOUND 4.4.11 / IAS15 等质量双体的一轨相对周期偏差 `2.22e-16`，相对间距偏差 `2.22e-16`，质心漂移 `0 AU`，独立重算能量和角动量相对偏差分别 `4.44e-16` 和 `2.22e-16`，均低于预设 `1e-6`。同参重跑样本一致。固定三体短程样本与收紧至 `1e-12` 的参考积分在导出精度下相同。 |
| 下载与授权 | 实验 ZIP 中清单所列的 6 个文件均通过 SHA-256 核验。快照 CSV 有 258 行，归档内所选时刻的 SVG 与同一时刻预览字节一致。两账号及项目范围校验 17 项拒绝均符合预期，匿名读取返回 401，缺少 CSRF 的写入返回 403。 |
| 运行边界 | `128 × 512` 最大配置网格短程样本成功，结果约 4.79 MiB，近零初值的相对诊断留空。径向近接终止并拒绝下载失败结果。Worker 使用无网络、只读根文件系统、非 root，只有专用交接卷，限制为 1 vCPU、512 MiB、24 个进程。实测一次运行约 45.83 MiB 内存。 |
| 重启、撤权及恢复 | API 重启保留同一运行试次，运行中取消后无成功产物。Worker 重启标记中断，不自动重跑。停用合成账号后拒绝读取并取消其运行中任务。真实 120 秒上限从 API 入队到观察到失败共 122.59 秒，后续任务成功，证明执行槽已释放。独立 PostgreSQL 最终备份恢复后 20 条任务记录、参数摘要和结果哈希一致。 |
| 依赖 | npm 生产依赖审计 0 项。完整审计仍报告 `picomatch` 的既有开发依赖公告，记录 13 项高危、0 项严重。V1.6.0 的例外没有扩展到 V1.7，生产前端容器没有安装这些开发工具。 |

起初 Ruff、格式和 ESLint 未通过，已保留日志并复验通过。修复了数值 `1` 被接受为确认，以及快照归档取末时刻而非页面所选时刻的问题。首次真实容器测试因合成账号 ID 格式不符而无法创建项目，随后用规范 UUID 的独立合成账号复验。首次重启组中的账号停用检查误用了另一账号的客户端，使长任务留在队列并妨碍下一用例。相关失败及合成任务收尾记录保留。

本次使用固定样本验证计算内核及边界。第三方模型的生成质量、外部星表服务、真实邮件、GPU、多机压力及人为触发容器内存耗尽不在本轮范围。Worker 内存配置和最大网格已有实测，结果不能推及所有轨道和粒子组合。

首次更新日常 `127.0.0.1:5173` 时，后端、前端与计算 Worker 已切换到验收通过的镜像，7 个服务健康。该阶段日常 PostgreSQL 缺少计算任务表，因此开关保持关闭。[首次部署核验](deployment-disabled.json)

Worker 空闲约 20.93 MiB，测试中长任务约 45.83 MiB，均为单点实测。计算镜像和后端镜像共享运行层，Docker 所报完整体积相差约 3.83 MiB。本次验收创建的容器、数据库卷及交接卷已按项目标签核对并清理，交接目录中遗留试次为 0。见[占用与清理记录](resources-and-qa-cleanup.json)。

2026-11-18 获得明确授权后，先生成日常 PostgreSQL 私有备份，核对归档目录和 SHA-256，再以应用角色应用新增计算任务表的事务。只读目录检查确认表归 `astroagent` 所有、5 个有效索引（含主键和唯一约束自动建立的索引）、身份外键有效、无公开权限。计算开关已持久保存为启用。7 个服务和 Worker 心跳健康，登录与激活页面均返回 200，匿名会话查询返回 401。现有 PostgreSQL、模型、绘图执行器和入口容器及其挂载均核对保留。[启用核验](deployment-enabled.json) · [表目录检查](deployed-compute-catalog.json)
