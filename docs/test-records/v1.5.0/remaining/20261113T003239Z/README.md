## 模型的实际边界和失败修复

冻结计划记录于 `quality-plan.json`。`quality-first.jsonl`、`quality-run1.jsonl`、`quality-run2.jsonl`、`quality-compact.jsonl`等保留了超时、无效单位、长编号变形、虚构距离及误述pmra的失败。没有将这些输出算作通过，也未豁免它们。

本版因此仅交付受限模式：有界规则提取支持的明示编号、坐标、角半径、年份范围及质量阈值；模型只建议任务类型，不生成测量值。摘要由模型选择原文片段，程序保留数字、单位、来源和限制语句；格式整理完整保留原文。自由科学改写与模型自由生成条件未达到标准，不在本版能力范围内，界面和文档均已说明。`quality-run3.jsonl`的50条标题与 `quality-bounded.jsonl`的44条受限操作构成最终质量证据；后续仅增加澄清提示、保护可容纳的短目录编号，标题/文本/必需字段原输出未变。评价由独立验收代理按冻结标准进行，不是被测Qwen自评，也不是人工接受率。

摘要可能遗漏非关键段落；条件语法有支持范围，不保证识别任意天体名称或自然语言。任务建议不执行实际查询、代码、文件或网络操作。输入中的恶意命令只作为文本；第49条不会删除会话或执行HTML。

## 数据、资源与限制

所有数据库压力和命名竞态使用独立随机测试容器/数据库，结束后只清理新建的对应容器及卷；从未连接Windows原生库。浏览器使用独立合成服务和临时数据。真实模型验证仅处理冻结合成文本，不访问日常会话；真实隔离探针不访问数据库。既有容器数据卷、模型和科研文件保留。临时浏览器配置归档为文本后删除。

Ollama模型身份固定为Qwen3-4B-Instruct-2507/Q4_K_M；默认4线程、5GiB上限、120秒请求期限，自动命名额外等待仍最多60秒。原阶段最大观测约4.4GiB，不视为连续峰值测量；受限操作耗时与当前空闲资源快照单列，磁盘数值为当时余量，不把Docker虚拟磁盘与内部逻辑层再次相加。

网页/后端/绘图任务不挂载Docker Socket；仅内部受信执行器持有。Socket只读挂载仍赋予守护进程控制权，被攻破可能影响同一Docker环境的其他资源；与独立虚拟机隔离不等价。本版限本机单用户，不宣称公网强对抗部署、GPU或跨机器部署已验收。源码发布不包含凭据、模型、安装包或个人科研数据。
