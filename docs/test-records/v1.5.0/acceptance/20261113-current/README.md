## 数据与限制

离线浏览器检查使用合成测试服务和临时数据。真实容器库自上轮后已有其他项目，本轮只在新建的合成项目/会话中进行写入，未迁移、覆盖或删除原项目；它不等同于完全独立的新数据库。真正的数据库集成使用临时新容器和新数据库，不接触该库或 Windows 原生库，临时容器及其卷在结束后清理。报告去掉了可能包含现有会话标题的截图附件。

本轮仍未完成：V1.5固定50条本地模型质量样本及自动命名完整竞态/异常矩阵、项目完整归档恢复与科研流程在新版页面的端到端浏览器复验。首次扩大浏览器运行有这些用例失败/中断，未将其算通过；后端项目/流程回归不替代对应浏览器证据。GPU、跨机器部署、真实SIMBAD/ADS未覆盖，Gaia按既有授权不作为本轮联网门槛。未要求人工替代自动验收。

内部绘图执行器仍持有 Docker 守护进程权限；不可信任务与网页/后端无Socket挂载，但这与专用虚拟机隔离不等价。完整版本验收尚未完成，本轮不创建标签或发布版本。资源空闲快照见 `resources.txt`，并非峰值。
