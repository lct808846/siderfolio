## SIMBAD 限制与失败导出

完整联网报告中，独立 SIMBAD、名称→Gaia、三工具场景的 SIMBAD 结果均为 `simbad_timeout`。不能据此确认远端维护或全球不可用。名称链路未伪造坐标；三工具保留 Gaia / ADS 成功数据，顶层状态为 `partial`。

上述三个失败场景仍实际取得 HTTP 200 ZIP、完成解包与逐文件哈希核对，包保留原失败状态和错误。它们的复合验收项因查询成功条件未满足而标为失败，不能用“下载成功”替代数据库成功链路。

客户端可自行提交快照，固定标注 `client_supplied_snapshot`、`source_authenticity_verified=false`。复算一致和哈希一致均不认证真实来源或科学结论。
