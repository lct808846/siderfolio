## 关键验证

- 普通用户不能读取或修改服务商配置；管理员仍须有效 MFA、CSRF 与写入时权限核对。按当前模型设置方案，模型配置不要求五分钟内再次认证，而账号管理仍保留该要求。
- 列表和设置状态不返回密钥；数据库保存的是身份密钥加密后的配置。留空只保留同地址、同协议的原密钥；地址或协议变化要求重填。过期修订拒绝写入，删除服务商不删除科研记录。
- 目录读取禁止回环、内网、链路本地地址及重定向；仅显式本机模式允许已规定的代理 Fake-IP DNS 网段。四种目录格式、去重、无效条目过滤与分页提示均有合成响应验证。
- Responses、Anthropic、Gemini 验证完整文本、工具调用与回传、原始状态保留、超时、鉴权、限额和格式错误；不完整回答不能执行部分工具。OpenAI Chat 使用实际适配器和本地模拟传输验证。
- MFA 关闭要求密码和验证码或恢复码；成功清除密钥、待绑定值和恢复码，撤销旧登录并可重新登录。管理员不能关闭必需的 MFA。
- 会话列表使用管理标识；只能在本人会话中解析。当前浏览器不能从列表撤销；单独退出其他浏览器保留当前登录。伪造及另一账号的标识均拒绝，另一账号保持有效。
- 登录错误密码不提前打开验证码步骤，正确密码后再要求 MFA；激活页确认密码不一致时不提交，保存后通知等待的登录标签页，不自动发起登录。
- 设置请求失败时清除旧就绪值，显示未确认和错误提示。模型切换、附件预览、布局切换不自动发送问题；错误重发必须显式点击并保留原问题。
- 服务商密钥字段在两个浏览器中遮挡字符、关闭自动填充，保存后编辑不回填密钥，浏览器持久存储没有测试密钥。
- 设置与服务商弹窗检查 1440、1280、1024、768、681、680、390、320 CSS px；其他相关工作区覆盖桌面及窄屏，另有 980/981、1439/1440 断点、低高度、键盘、强制颜色和减少动态效果检查。截图见[视觉与交互记录](../../ui-consistency/20261115T074824Z/README.md)。

## 失败保留与处理

1. 首轮 Ruff 有 54 项导入/行宽等问题，格式检查和 ESLint 两处警告未过。仅修正相关源文件的格式与导入顺序，收尾检查通过；没有降低检查标准。
2. 账号页面改为设置弹窗、模型显示名称及重发文案变化，旧测试继续定位移除的控件或旧导入路径。更新测试操作入口与模拟适配边界，保留原有发送次数、错误、数据与权限断言。初始单元、离线和浏览器失败日志仍在。
3. 首轮会话不存在测试传入不符合长度约束的标识，得到 422；改为格式合法但不存在的标识，验证 404，并追加真实跨账号标识断言。服务端校验未放宽。
4. 默认受限进程中的首轮离线测试停滞、浏览器服务未就绪，核对并停止本轮确切进程后重跑；见 `initial-run-interruption.txt`，不记作通过。
5. 一条新增 OpenAI 合成适配器测试的传输替身未覆盖代理，导致无效合成密钥请求到达服务商并收到 401，见 `offline-final.txt`。未使用真实模型密钥。补强 `tests/conftest.py` 同步和异步发送前的离线保护，并改用显式 MockTransport；代理拦截专项通过，最终离线测试没有依靠外部响应取得通过。
6. 业务界面首轮选定集为 40 通过、4 旧定位失败、2 个可选公开 PDF 样本跳过，见 `browser-rerun.json`。后续范围排除未提供的可选 PDF 样本；本次文献上传、检索、原文、下载、长文件名仍有自动测试。
7. 扩展集的设置状态测试两浏览器首次失败：旧合成服务没有新增服务商只读接口，触发身份过期处理。为该离线服务补充只读合成接口后，两项复验通过。真实身份/数据库接口另由未绕过鉴权的独立数据库测试覆盖。

## 数据保护、资源与限制

所有数据库测试使用随机命名的一次性 PostgreSQL 容器及专用库，复用现有固定镜像；每次测试自行删除所创建的库和容器。业务浏览器使用临时合成数据与独立端口，邮件浏览器使用合成邮箱页面。本次未清空、恢复或迁移日常库，未更改个人账号、模型配置、SMTP、认证密钥或科研文件；未下载模型或虚拟机。

当前前后端镜像已重建并更新，仅替换相关容器，保留原私有配置和数据卷。`cleanup-check.json` 确认无遗留 QA 容器，`test-services-cleanup.json` 记录测试服务已停止。六个日常容器内存快照合计约 603 MiB，见 `resources-final.json`；这不是 Docker/WSL 整体占用，也不包括推理峰值、内核及文件缓存，未据此推断磁盘释放量。

本次不重复未改动的真实天文查询、嵌入模型质量或绘图执行器全链路；浏览器科研结果与新协议上游均为合成数据，不能据此宣称科学质量或所有真实服务商连通通过。没有新增真实 SMTP 发信，也没有再次调用已记录余额不足的 Gemini 服务。浏览器/扩展原生密码保存提示不能由字段属性完全控制；本轮验证字段遮挡和保存方式，不认证所有扩展行为。未执行公网 HTTPS、所有浏览器组合或系统级 200% 缩放认证。

当前设置方案只向已完成 MFA 的管理员提供控制台入口；与早期清单“任何登录后页面都无入口”的表述不同，普通用户无入口及服务端拒绝越权已验证，不把早期绝对无入口断言冒记为通过。版本仍为 V1.6 开发版，本轮没有创建 GitHub 稳定版发布。
