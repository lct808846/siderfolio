# V1.1 未提交改动：剩余自动验收

本轮保持应用版本为 1.1.0，使用独立代码快照、临时数据库、公开论文及合成材料，不使用个人日常数据库。上轮用户确认结果栏当前入口满足验收，原先历史报告保留当时结论，此后不作为阻碍。

- 原先跳过的公开 PDF、256 MiB SQLite 替身和 PostgreSQL 逻辑数据上限：3 项通过。SQLite 属于替身；PostgreSQL 使用可压缩合成数据，不构成物理磁盘容量或性能验证。
- WSL 中直接调用两项现有 Linux 测试函数，内存、文件大小和 CPU 限制均通过；该环境没有安装 pytest，因此记录为直接调用而非完整 Linux 测试套件。
- 当前真实服务：SIMBAD 2 项、ADS 6 项通过；Gaia 首次 5 通过、2 项超时，失败项重试均通过，首次失败记录保留，说明连接可能间歇不稳定。
- 两种浏览器补测复制和权限失败、等待回答时的结果栏、非当前会话重命名/置顶/导出、多选删除部分失败、设置刷新失败、项目路由与低窗口高度、减少透明效果。各次报告详见同目录 browser-*。
- 实际 PostgreSQL 和本机模拟回答服务上，两种浏览器完成问答模型选择、预览、取消、确认生成和原文回查；实际发出的模型、问题和证据与预览一致。测试不发送私人文献。
- axe 自动审计工作台、项目和设置页的 WCAG 2 A/AA 规则，两种浏览器通过；测试环境仅为注入审计脚本临时绕过 CSP，不代表真实屏幕阅读器或所有设备均已验证。

第一次 RAG 发送内容测试将 JSON 转义文本当原始字符串比较，脚本改为解析 JSON 后通过；首次界面测试脚本漏引入路径模块，修复后通过。两次原始失败均保留。自动检查不能证明科研回答的科学忠实度。最终提交和远程 CI 以实际后续结果为准。

- 加入 RAG 确认发送测试后，隔离快照的最终后端回归为 549 通过、20 按默认配置跳过；Ruff 检查、格式检查和 pip check 均通过，详见 `offline-final`。上列额外执行分别覆盖这些跳过项目。报告中安装环境的 `astroagent` 分发元数据为 0.8.0，而本次使用的源码及应用版本为 1.1.0；不能将安装元数据当作源码版本。
- 真实 PostgreSQL 的空数据库通过设置页面确认初始化后，两种浏览器完成 RAG 确认及原文回查；真实回答服务由本机合成服务替代，见 `rag-ui-settings`。
- 边界宽度侧栏测试在 `browser-sidebar` 中两种浏览器通过，但 `browser-sidebar-final` 中 Edge 在切换时的 `aria-expanded` 断言失败。调整测试在改变视口后等待两个渲染帧，再次运行两种浏览器均通过，并在两种浏览器中各重复 3 次通过，见 `browser-final-recheck.json` 和 `browser-final-repeat.json`。首次失败原因未经证实，原始记录保留。
- 非当前非空会话导出在两种浏览器均验证了问题轮次，见 `browser-final-recheck.json`。导航测试中的知识库路由使用的旧模拟后端缺少 RAG 服务，路由本身的加载和选中状态通过，不能以此证明该后端的知识库功能。
