## 已验证的使用流程

浏览器使用生产 `dist/`、独立本机静态服务与API代理，测试会话新建→发送→修改RUWE追问→完整表翻页→三图预览→下载→刷新路由恢复→选择历史轮次→改名→确认删除。中文输入法组字Enter不误发；失败发送保留原问题，仅点击才重试；不从原始HTML探针创建元素，不访问 `javascript:` 来源链接。

后端HTTP脚本实际启动临时Uvicorn，交付100行合成数据并验证新查询继承完整条件，原请求键重复提交返回同一轮次。下载的ZIP与清单逐文件哈希一致，预览PNG来自同包；服务重启后完整结果仍在，运行中断标为 `interrupted`，复用原键不重放模型。随后重新生成原轮次产物并核对，再改名/删除。所有临时服务记录PID退出和端口关闭，专用库在服务停止后清理，未归档个人会话库。

新后端用例还覆盖同会话忙/全局两任务（包含原无状态聊天）、幂等异体冲突、修订冲突、配额预留与改名预算、失败提交、schema迁移备份/回滚/高版本拒绝、未知/过期产物、损坏PNG拒绝、跨会话从属关系、Host/Origin/CORS和分块超限。上下文保留最近六个可交付轮次且最多64 KiB，整轮移出；完整API数据保持100行，模型视图保持十行和完整程序统计。

- 各可交付轮次的产物生成、清单/PNG/ZIP哈希核对通过；真实失败状态仍保留。客户端来源真实性标记仍为 `client_supplied_snapshot`、`source_authenticity_verified=false`。
