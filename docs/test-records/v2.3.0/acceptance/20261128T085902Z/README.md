# V2.3.0 修复复验

本机以 `464e249` 为基线，在 V2.3 工作区复测受改动影响的路径。复验通过。上一轮失败记录保存在 [首次验收](../20261128T084721Z/README.md)。

## 修复内容

- 表格检查和上传接入既有 multipart 接收边界。单个文件依旧受 10 MiB 限制，身份验证、同源和 CSRF 检查继续生效。表格删除支持前端原有的空请求体。
- 下载提供 ASCII 备用名与 UTF-8 扩展名。浏览器下载优先使用完整的中文名称。
- 拟合卡片兼容缺少摘要的历史数据。修复直接绘图弹窗的无用赋值，处理 Python 静态检查，更新文献技能回归中的当前标题。
- MCP 取消回归先建立连接，再测试占用、取消与回收后的重连。复测采用原有服务启动时限及原有调用和连接池等待时限。
