## 功能阻塞

- **文件检查与上传返回 415。** 新增的 `/tables/inspect` 和 `/tables/upload` 路由接收 multipart，但进入路由前被 `LocalAccess` 按 JSON 请求拒绝。两个路由在合成项目上分别复现，并于首次测试后独立重跑。
- **中文表名导出 CSV 返回 500。** 表名中的中文被保留在 `Content-Disposition` 的普通 `filename` 值里，响应头编码抛出 `UnicodeEncodeError`。隔离 API 实测 500，ASCII 文件名的 FITS 下载基准通过。
- **完整浏览器验收待复测。** 当前上传受 415 阻断，类型检查也阻断正式构建。桥接测试验证了应用生成并登记绘图数据，实际渲染仍需随完整链路复测。

数值基准使用合成数据与 Astropy 8.0.2、NumPy 2.5.4、SciPy 1.18.1。坐标往返误差阈值为 10⁻¹⁰ 度，球面角距容差为 10⁻⁶ 角秒。数据库用例在自动创建的一次性 PostgreSQL 17 和 pgvector 0.8.7 容器中运行，容器已停止。测试脚本、各轮 JUnit 结果及失败输出位于本机 `outputs/v23-acceptance-20261128T084721Z` 下。其中数值用例的首轮和第二轮记录包含测试脚本的格式与列名修正，表格 API 的下游复测修正了测试中的右表列名。
