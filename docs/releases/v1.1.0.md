# AstroAgent V1.1.0

V1.1.0 完善查询、项目、知识库、文献问答、科研流程和设置页面的导航与阅读层级；中小屏可切换面板，草稿在切换时保留。界面提供毛玻璃层次和系统字体回退，并改善设置状态与项目操作错误的提示。

本版继续使用 PostgreSQL schema6、项目归档格式5和原有文献问答预览与确认流程。数据库、模型和个人文献不会包含在源码发布中，迁移与备份请参阅 [操作指南](../OPERATIONS_V1.0.md)。

本机自动回归中，后端与 PostgreSQL 536 项通过、20 项跳过；前端单元测试 15 项通过，Chromium 和 Edge 浏览器回归 26 项通过，随后补测两项公开 PDF 通过。实际 PostgreSQL 浏览器预览和取消、多个屏宽和键盘辅助显示检查通过。真实 Gaia 7 项、SIMBAD 2 项和 ADS 6 项通过。详见 [V1.1.0 验收记录](../test-records/v1.1.0/README.md)。

浏览器截图和测试使用合成数据；多语检索的代表性、回答的科学忠实度及完整屏幕阅读器兼容性不能由这些自动检查证明。源码发布不包含安装程序、数据库或嵌入模型。
