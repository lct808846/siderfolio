### 天文星表与科研工作台

- 新增 VizieR 只读星表检索，支持将 Gaia DR3 和 VizieR 的查询结果保存为项目数据表。
- 支持 FITS 表、VOTable、ECSV、CSV 和 TSV，保留原始单位、参考历元及 64 位源编号。数据表可预览、导出或交给现有隔离绘图服务。
- 在对话中核对后执行描述统计、筛选与派生列、天球坐标变换、球面交叉匹配和科学曲线拟合。运行记录保留参数、数据来源、软件版本和边界提示，支持下载 ZIP 复现包。
- 扩展表格分析科研技能和运行追踪，便于查看一次对话中使用了哪些数据源和工具。
