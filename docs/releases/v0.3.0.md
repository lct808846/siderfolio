# AstroAgent v0.3.0

发布日期：2026-10-28。包版本与 OpenAPI 版本为 `0.3.0`。本次为源码发布，提供 Git 标签、GitHub 自动源码归档及测试记录，不附带安装器。

## 新增能力

- `query_gaia`：固定 Gaia DR3 `gaiadr3.gaia_source`，按字符串编号精确查询或按 ICRS 中心与半径查询位置候选源。圆锥半径最多 30 角分，交付最多 100 行；可选 RUWE 与正视差信噪比筛选。
- 固定 ADQL 与同步 TAP POST；记录实际查询、字段单位、参考历元、来源 UTC 时间、哨兵行截断与服务端 OVERFLOW。关闭重试/重定向，连接与读取受超时约束，解压响应最多 2 MiB，拒绝 XML 外部引用和无界分配提示。
- 对交付行计算六列有效/缺失数、中位数、最小/最大值及负/零/缺失视差数。仅显式要求时估算距离：正视差、正误差、SNR≥10，以 `1000/parallax` pc 及一阶随机误差计算；不满足条件保留跳过原因。
- 三工具共用预算、批次参数验证和失败降级。API 保留完整测量/分析，模型仅见前 10 行及其距离，完整样本统计与计算/跳过数始终保留。后续模型失败不会丢弃已取得的数据。
- 新增独立 `ASTROAGENT_RUN_LIVE_GAIA`、`scripts/run_tests.py --live-gaia` 和十二项真实 HTTP 验收 `scripts/verify_v03.py`。记录按版本/类型/UTC 时间保存，包含依赖与 Git 状态；修复 Windows 控制台 Unicode 输出导致报告中断的问题。

## 兼容性和配置

保留 `POST /api/v1/chat` 的路径和请求格式；`results` 只含 SIMBAD，`literature_results` 只含 ADS。新增 `gaia_results=[]`，`Source.name` 增加 `Gaia`；严格校验响应字段或来源枚举的客户端需要更新。

新增 `GAIA_TIMEOUT_SECONDS=20`（大于 0、不超过 120 秒）。公共 Gaia 查询不需要 Archive 账号或 token；自然语言聊天仍需模型密钥，ADS 单独需要 ADS token。健康检查、OpenAPI 和服务构造不访问 Gaia。

新增显式依赖 `astropy>=6.1,<9`、`defusedxml>=0.7.1,<1`；执行 `python -m pip install -e ".[dev]"` 更新本地环境。

## 验证与已知限制

完整离线回归：290 项通过、15 项联网测试默认跳过；Ruff 检查/格式、`pip check` 通过。真实 Gaia 编号、圆锥、筛选、无匹配和模型距离解释通过。完整 Gaia 联网测试 5/7 通过，HTTP 验收 9/12 通过；未通过项涉及 SIMBAD 超时，三工具结果保留 Gaia / ADS 成功数据并返回 `partial`。HTTP 临时服务进程已退出，端口已关闭。

**本版本在保留上述外部连接失败的情况下，按用户 2026-10-28 的明确授权发布。** SIMBAD 主站及哈佛镜像在当日本机探测中均超时；是否为网站维护尚未确认，不能据此断言全球服务不可用。相关调用可能返回 `simbad_timeout`，名称 → Gaia 链路会停止，联合查询会保留其他成功结果并返回 `partial`。

失败报告与修复后的新记录均保留，入口见 [V0.3 测试记录](../test-records/v0.3.0/README.md)。本次豁免仅针对已记录的 SIMBAD 外部连接限制；离线测试、Ruff、依赖检查及目标提交的主分支/标签 CI 仍作为发布检查。SIMBAD 访问恢复后仍需补验名称链路、SIMBAD 回归与三工具完整成功路径，不能将当前失败改写为通过。

## 科学与产品边界

圆锥结果是位置候选源，不能直接确认名称匹配或星团成员；不做自行传播。`pmra` 已包含赤纬余弦因子。统计仅限交付行，`total_found=null`，不自动翻页。距离近似未校正视差零点、系统误差、选择偏差或消光，不提供贝叶斯距离；不能把它当作 Gaia 直接测量。没有任意 ADQL、参数反演、图表/文件导出、前端、记忆或多 Agent 功能。
