# AstroAgent V1.0.0

V1.0.0 引入 PostgreSQL 和 pgvector 存储、固定本地多语言嵌入模型及索引、单项目混合检索、文献证据预览与发送确认、引用回查、问答历史和设置页面。旧聊天不会自动读取文献，用户确认前不会向回答服务发送原文。

数据库使用 schema6。旧 schema5 仅作为只读迁移输入，不自动双写或回流；原文件及其位置仍是来源，向量是可重建的派生数据。项目归档格式 5 可保留 RAG 历史及最小请求历史，支持导入格式 1–4；有 RAG 历史时拒绝导出旧格式，避免静默丢失。迁移前请按操作文档备份，并在独立目标库演练。

- Windows 本地 PostgreSQL 全量测试 536 通过、20 跳过；一次测试文件格式检查失败后已修正，并单独复查相关测试与规范检查。
- 修正后的验证提交 `a53c6e0` 在 [远程 CI](https://github.com/lct808846/astroagent/actions/runs/41371340439) 中通过后端、PostgreSQL 和前端检查；后端 508 通过、48 跳过，前端浏览器测试 12 通过、1 跳过。
- 基于两篇公开论文的固定小样本自动检索评估达到该方案的门槛；样本不代表完整文库，自动核查不能证明回答的科学忠实度。
- Gaia 真实网络查询此前超时，用户明确允许本次作为例外；这不表示 Gaia 查询已通过或故障已经修复。
- 检索模型与 PostgreSQL 需按部署文档单独准备；源码发布不包含模型、数据库或安装程序。
