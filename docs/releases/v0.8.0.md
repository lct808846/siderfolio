# V0.8.0：本地知识库与原文证据

日期2026-10-30。远端发布状态以 [GitHub Releases](https://github.com/lct808846/astroagent/releases) 为准；本地样本和验收边界见 [测试记录](../test-records/v0.8.0/README.md)。

## 新增代码

- 项目“本地知识库”入口：上传文本型PDF或UTF-8 Markdown，保存原始字节、哈希、用户元数据和不可变文件版本。
- 受限子进程提取：PDF物理页、空页/失败页、Markdown原始行号和章节；1200字符分段、最多120字符重叠。支持查看实际提取文本、受限原文件预览和完整下载。
- FTS5 unicode61/trigram词法检索，短中文有界扫描；只检索当前可用版本，返回原文、页码/行号、版本与引用ID。所有关键词同时匹配，无命中为 `insufficient_evidence`。
- 摘录式回答不调用模型、远程嵌入或外部科研服务。它不推断结论；命中原文不等于支持用户命题，也不代表全文已正确解析。
- 替换建立新版本；显式恢复/重建索引保留历史引用。查询证据时核对原文件、分段、位置与哈希；删除使旧引用失效，不用新文件代替旧原文。
- 格式3归档明确选择“完整备份（含原文）”或“仅元数据”。含原文需单独确认数量和大小；仅元数据移除文件及提取原文，但保留标题、检索词和项目记录，恢复后原文不可用，可提供同哈希文件恢复。

## 存储、依赖和边界

SQLite schema3→4新增文档、版本BLOB、提取文本、分段、证据、操作记录及FTS索引。迁移前生成 `migration-v4-<UTC时间>.sqlite3` 一致性备份，失败回滚；验收使用临时库，未迁移个人库。回退V0.7需要独立目录中的schema3备份，不能直接降级写入。

格式3固定六成员：`manifest.json`、`project.json`、`conversations.json`、`snapshots.json`、`workflows.json`、`knowledge.json`。原文件以base64保存，索引不打包；校验通过后本地重建可用索引，不启动解析或查询服务。格式1/2仍可导入；知识库或相关历史存在时禁止省略它们导出旧格式。

新增依赖声明：`pypdf==6.21.4`、`python-multipart==0.0.32`、`starlette>=0.47.3,<1`。已在本机 Conda 环境安装并通过 `pip check`。PDF提取不执行OCR，复杂布局可能缺漏，见 [pypdf官方说明](https://pypdf.readthedocs.io/en/6.21.4/user/extract-text.html)；索引规则依据 [SQLite FTS5文档](https://www.sqlite.org/fts5.html)。

文件20 MiB、项目100文档/200版本、PDF500页、Markdown200000行、版本文本20 MiB/25000段；项目500次操作/1000条证据引用。原文、文本、索引实际载荷和预留共用原256 MiB业务预算。解析30秒/768 MiB内存/64 MiB输出；Windows 已检查内存上限、超时终止和保护不可用时拒绝解析；Linux 已实际触发内存、CPU 和文件大小限制。索引缺失不阻断旧聊天/项目。
