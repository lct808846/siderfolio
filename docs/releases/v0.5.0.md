# AstroAgent v0.5.0：Web 工作台与连续对话

本版按 2026-10-29 用户“发布新版本”的指令执行源码发布；本地检查、目标提交和标签 CI 均为发布门槛。真实联网验收仍有 SIMBAD 相关缺口，按已知限制如实保留。实测证据见 [V0.5记录](../test-records/v0.5.0/README.md)。

- Vue 3、TypeScript、Vite、Vue Router、Pinia独立中文前端，桌面三栏、窄屏面板切换；展示完整SIMBAD/ADS/Gaia响应、条件、单位、来源和历史标记。
- 新增本地会话CRUD、轮次保存/读取、修订冲突、请求幂等和明确失败状态。SQLite短事务不覆盖外部模型/工具调用；重启将遗留运行轮次标为中断，不自动重放。
- 共用原有Agent执行循环，新增最近六轮/64 KiB历史模型窗口；整轮移出并记录原因。旧 `chat(message)` 保持无状态，本轮结果只记录新执行工具，历史引用保持原轮次和时间。
- 从指定已保存轮次复用V0.4导出器。预览PNG与下载ZIP来自同包；严格验证完整快照、2 MiB导出边界、清单哈希和白名单成员。产物缓存最多八个/64 MiB/15分钟，满额明确拒绝。
- 原API与新会话共享进程内最多两轮模型任务；本机Host和明确Origin检查、分块实际字节上限、无外部脚本/HTML解释。缺密钥可浏览、预览和导出历史。
- 固定前端锁文件，从实际OpenAPI生成TypeScript契约；增加独立静态服务/API代理、前后端检查、重启/联网验收和wheel安装验证脚本。

限制仍为可信本机、单用户、单后端worker。会话最多20个、每会话40轮，单轮记录16 MiB，全库业务内容和预留256 MiB；不保证SQLite物理文件等于该字节数。数据目录必须为本机磁盘，使用SQLite备份接口和schema版本检查，不静默重建未知库。

本轮真实Gaia圆锥→RUWE条件追问、ADS论文→历史DOI引用、精确源→距离解释及产物校验通过；SIMBAD名称链路与三工具完整成功路径仍未通过，失败状态和其他成功数据保留。不能把下载成功当作完整科研查询成功。

没有新增账号、云同步、流式token、任务队列、自动重试、硬取消、RAG、全文下载或新科学推断。浏览器断开不会自动取消后端，也不会自动发起新的收费请求。构建wheel仅用于本地包边界验收，不表示发布安装器。
