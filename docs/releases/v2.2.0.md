V2.2.0 交付 Agent 长期记忆与上下文管理、多模态图片附件分析、品牌视觉与工作台交互精修，并将代码仓库正式命名为 `siderfolio`，同时重写项目首页文档与实际运行示例。

- **Agent 长期记忆与上下文管理**：支持在对话中显式保存研究方向与偏好（附回执卡片），默认开启有界长期记忆提取与跨会话召回，超过 24 轮的长对话自动生成结构化摘要压缩并保留原始轮次与来源追溯；设置页新增「长期记忆」极简摘要视图与添加入口，运行追踪同步记录脱敏记忆条数、检索模式、摘要覆盖轮次与跨会话「历史」原轮次跳转，并支持与内置科研技能匹配联动。
- **多模态图片附件上传与净化**：对话附件新增 `.png`、`.jpg` / `.jpeg`、`.webp`、`.gif` 图片支持，经后端 Pillow 校验、EXIF 方向规范化、去元数据重编码与分辨率/体积收敛后安全传入多模态模型，前端同步支持图片预览与多模态结果展示。
- **工作台交互与品牌细节优化**：精简查询输入区交互，强化邮件模板与身份验证器品牌图标显示，统一修复多处旧版文案与窄屏计算结果交互细节，并新增受控本地 HTTPS 外部 MCP 联调测试服务端。
- **自动发布更新日志增强与文档重写**：发布流水线支持按 `docs/releases/vX.Y.Z.md` → 附注标签正文 → 提交记录自动生成 Release 更新日志；全面重写 `README.md`，补充项目实际运行截图、系统架构图与技术栈说明。
- **向后兼容增量建表**：各账号私有 schema（`aa_<32-hex>`）幂等新增 6 张记忆与会话摘要表（`memory_meta`、`memory_preferences`、`memories`、`memory_candidates`、`memory_vectors`、`conversation_summaries`），不改动 `public.*` 及既有会话、项目、文献、RAG 与计算数据。
