# V0.9.0：项目来源集成

本版提供项目来源总览和用户显式引用；不是 V1.0 稳定版。按用户决定，Gaia 真实联网验收未通过作为本次发布的已知限制保留，后续版本再试。远端发布状态以 GitHub Releases 为准。

## 新增行为

- 项目总览集中列出会话轮次、快照、科研流程、本地文档和用户关联；来源按数据库测量、ADS书目/摘要、原回答/程序说明、文献原文和用户备注区分。
- 三类项目结果可与同项目的固定证据建立 `user_reference`。创建前核对原文版本、位置和哈希，并由用户确认；关联不表示科学支持、反驳、成员关系或因果证明。
- 幂等创建、同两端去重、带双修订的备注更新、稳定分页和显式解绑。解绑保留两端数据，原请求重放不会重新建立关系。
- 删除结果、移动/删除会话或删除文档保留失效记录；移回原会话或出现同名文档不会自动复活旧关联。仅元数据缺原文与真正删除区分，同哈希与固定位置恢复后可重新核对。
- 快照、流程与知识库入口能跳到总览建立关系；会话跳转定位具体轮次，历史证据保持原文件版本。关联不改写旧ChatResponse、sources或科研统计，不向模型发送文献。
- 格式4项目包增加 `links.json`，保留关联、操作历史及软引用；兼容格式1–3导入，旧包关联为空。格式4继续区分含原文完整备份与仅元数据，逐层映射新ID并标记导入未认证。

## 数据与维护

SQLite schema4→5新增关联与创建请求表。首次启动前使用一致性备份保存 `migration-v5-<UTC时间>.sqlite3`，失败回滚；V0.8不能直接写schema5。本轮未启动应用或迁移个人库。

每项目最多1000关联、3000创建请求历史；API列表最多100条，页面每页25条。记录、备注、操作历史和身份映射计入原256 MiB业务预算。有不支持的数据时拒绝旧格式导出，包含解绑后仍保留的创建历史，不能无提示省略。

新增 `scripts/manage_data.py` 的显式SQLite一致性备份与全新目录恢复工具，不覆盖日常库，不自动启动/升级；已用临时库演练。安装、升级、备份、两类恢复与数据保留卸载说明见 [操作稿](../OPERATIONS_V0.9.md)，平台与接口支持见 [V1.0候选契约](../V1_CANDIDATE_CONTRACT.md)。

## 交付状态

Windows 新环境离线 493 项通过、19 项跳过；Linux 新环境 492 项通过、20 项跳过；双浏览器 26 项通过。合成集成 30 项、schema5 升级与回滚、格式4恢复及两平台 256 MiB 边界专项通过。SIMBAD 2 项、ADS 6 项真实服务测试通过。

Gaia 真实服务 7 项因查询超时失败，后续重试仍超时；尚未确定是远端服务还是网络链路问题。两篇公开论文的小样本检索试评不代表真实文库；其他目标类型与辅助功能的人工覆盖、数量上限和恶意归档的组合未穷举。测试范围、失败记录及更多限制见 [验收记录](../test-records/v0.9.0/README.md)。
