# AstroAgent v0.6.0：项目与查询归档

本版在 V0.5 发布提交 `c057010` 基础上增加项目与查询归档，并修复 SIMBAD 主站故障时的镜像切换。以源码形式发布，发布门槛包括本地检查、目标提交及标签 CI。实测结果见 [V0.6验收记录](../test-records/v0.6.0/README.md)。

- 项目CRUD、会话归属与移动、独立元数据修订号；旧会话保留为未归档。关联会话的新轮次、终态与改名会更新项目修订号。
- 从已保存轮次复制完整命名快照，保存响应SHA-256、来源、原始编号和保存时软件环境。响应不可变；移除项目或快照时保留原会话。
- 用户确认单条工具的完整参数后直接重跑，不调用模型。新会话、轮次、快照和新旧关系独立保存；幂等先于修订检查，运行中同键202，重启标为中断，不自动重放。执行状态与数据状态分别显示。
- 两快照的条件、状态、计数、截断、来源和版本比较，保留缺失/null/未知。可显式按同源同模式同发布版Gaia字符串编号或ADS bibcode比较交付编号；不提供自动科研结论。
- 固定四成员项目ZIP、逐文件SHA-256、严格JSON与引用校验；流式检查实际接收/解压字节，完整验证后单事务恢复。新ID映射和归档来源保留，导入标为未认证；再次保存导入轮次不会提升其来源等级。
- schema2迁移前一致性备份、失败回滚；旧聊天、科学响应、统计与单轮导出规则保留。恢复快照可用同包PNG预览与ZIP下载。
- Vue项目页、未归档会话、桌面/窄屏布局、重跑确认与Escape取消、快照刷新恢复、比较及归档导入导出；共享既有结果核查组件和API客户端。

接入[哈佛SIMBAD镜像](https://simbad.cfa.harvard.edu/simbad/)后，本次真实联网 **21/21通过**：SIMBAD初次查询、直接重跑、名称→Gaia、三工具、项目归档与恢复均成功，SIMBAD来源链接记录实际哈佛站点。主站连接失败/超时或临时服务错误时才切换一次，不在未匹配或损坏数据时重放；两个站点保留独立有界会话。此前17/21及超时证据原样保留，不以新通过结果改写历史。

仍为可信本机、单用户、单worker，未新增账号、公网部署、RAG、流程编排、全文下载或科学方法。轮次/快照各受原存储和导出边界约束；所有副本计入全库预算。项目格式不包含预览缓存、环境凭证、数据库文件或其他额外用户文件。wheel只用于后端包边界检查，前端单独构建。

本次镜像修复后离线417项及真实SIMBAD两项回归通过；API与前端结构保持兼容。源码包不包含 wheel、可执行文件或安装器附件。
