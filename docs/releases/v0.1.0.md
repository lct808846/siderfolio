# AstroAgent v0.1.0

发布日期：2026-10-26。

首个可运行版本，提供自然语言天文查询：FastAPI 接收问题，由 DeepSeek 自动选择 SIMBAD 工具，返回真实天体数据、数据库来源和自然语言回答。

## 功能

- `POST /api/v1/chat`：单次、无状态自然语言查询；一般概念问题可直接回答。
- SIMBAD 名称查询：主标识符、ICRS 赤经赤纬（度）、天体类型、光谱类型及坐标文献编号；缺失字段为 `null`。
- 结构化 `results`、`sources`、`warnings`：程序记录实际查询与来源，不依赖模型生成链接；支持多目标和部分成功。
- 无匹配、数据库超时、模型认证失败、限流、网络失败和无效工具调用的明确错误处理；回答生成失败时保留已取得的数据。
- `.env` 与环境变量配置、查询超时及模型/工具调用次数限制。
- `/health`、`/docs` 和 `/openapi.json`。
- 离线测试、显式联网测试、真实 HTTP 验收、延迟测量及分版本测试记录。

## 验证证据

- 离线测试：42 项通过，2 项联网测试默认跳过；Ruff 代码、格式和依赖检查通过。
- 真实服务测试：SIMBAD Betelgeuse 查询及 DeepSeek 自动工具调用均通过。
- 实际 Uvicorn HTTP 验收：健康检查、Swagger HTML、OpenAPI、空白输入、Betelgeuse 查询、无匹配天体名称六项通过。
- 本机 Betelgeuse 串行查询 3 次平均完整响应时间约 5.27 秒；健康检查 5 次平均约 6.8 毫秒。这是少量样本，不代表并发性能或响应时间承诺。
- 原始报告、日志和校验值见 [v0.1.0 测试记录](../test-records/v0.1.0/README.md)。远程检查状态以本次提交对应的 GitHub Actions 结果为准。

## 从源码运行

需要 Python 3.12 或更高版本，以及用于聊天的 DeepSeek API 密钥。下载此标签的源码或克隆仓库后，在项目根目录执行：

```powershell
conda activate agent
python -m pip install -e ".[dev]"
$env:DEEPSEEK_API_KEY = "your-deepseek-api-key"
python -m uvicorn astroagent.main:app --reload
```

也可以按根目录 `.env.example` 配置 `.env`。完整安装、请求示例和错误约定见 [README](../../README.md)。

## 当前边界

本版通过 GitHub 标签与源码发布，不提供单独安装包。无前端、多用户、会话记忆、ADS 文献检索、Gaia、MCP、RAG 或生产部署。V0.2 ADS 文档是后续设计，不代表本版实现。

模型自然语言回答仍需对照结构化查询结果核查；未接入的距离、质量、亮度等字段不会作为数据库结果返回。外部服务状态与网络会影响查询成功率和耗时。
