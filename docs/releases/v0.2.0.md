# AstroAgent v0.2.0

发布日期：2026-10-26。ADS 文献检索与 SIMBAD 联合查询已实现，通过离线、真实外部服务与本机 HTTP 验收。记录见 [v0.2.0 测试记录](../test-records/v0.2.0/README.md)。

## 新增行为

- `search_ads` 使用真实 ADS Search API，支持主题、标题、作者、年份、bibcode 和相关性/日期/被引排序，每次获取一页。
- `literature_results` 保留每次检索式、分页、总命中数、原始摘要、完整作者与所有 DOI；缺失字段保留空值。每篇论文链接由程序根据 bibcode 构建。
- 同一请求可以执行 SIMBAD 与 ADS，两者共享调用预算；任一失败或后续模型失败，已执行结果仍保留。
- ADS 未配置、认证失败、限流、无效检索式、超时与坏响应均有稳定错误码，关闭自动重试和重定向。
- 模型上下文限制为每篇摘要前 2000 字符、前 5 位作者并标记截断，API 数据保持完整。相对时间使用请求时 UTC 日期。
- 修正 SIMBAD 初始化时先发元数据请求再注入超时 session 的顺序，使首次 TAP capabilities 请求也受连接/读取超时约束。

## 配置与升级

新增可选 `ADS_API_TOKEN` 和 `ADS_TIMEOUT_SECONDS=20`。token 只在执行 ADS 时检查；健康检查、离线测试和 SIMBAD 查询无需 ADS token。非法超时仍为 `invalid_configuration`。

`POST /api/v1/chat` 路径与 `message` 输入保留。响应新增默认空列表 `literature_results`，来源枚举新增 `ADS`；拒绝新增字段或只允许 SIMBAD 来源的客户端需要适配。`results` 继续只表示 SIMBAD 数据。

## 验证和限制

- 离线测试：147 项通过，8 项联网测试默认跳过；Ruff 代码、格式和依赖检查通过。
- 真实服务与模型测试：8 项通过，包括 ADS 固定文献、主题年份、无匹配、实际模型工具选择、SIMBAD 回归和合成恶意摘要探针。
- 实际 Uvicorn HTTP 验收：九项全部通过，临时服务已停止。中途 SIMBAD 外部服务波动的失败报告保留在测试记录中。
- 远程 CI 作为发布门槛，需与标签指向同一提交；具体提交和 GitHub Actions 运行链接附在 [GitHub Release](https://github.com/lct808846/astroagent/releases/tag/v0.2.0) 中。

本版通过 GitHub 标签与源码发布，不提供单独安装包。安装与配置示例见 [README](../../README.md)。

不包含全文/PDF、BibTeX 导出、Gaia、RAG、前端、会话记忆或生产部署。文献总结仅依据本次返回摘要，不能等同于阅读全文。恶意摘要的工具协议防护有测试，不能据此宣称消除了所有模型提示注入风险。

ADS 网页在本次内置浏览器中触发人工验证，未完成结果页的图形验收；API 检索与程序生成的来源字段已经验证。链接参数同时按 ADS 官方前端路由核对，API 结果中的实际条件是复查依据。
