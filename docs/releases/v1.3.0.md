# AstroAgent V1.3.0

V1.3 新增项目内数据绘图：导入 CSV、TSV 或已有 Gaia 查询快照，向模型明确授权发送数据摘要，审阅 Python 或 Gnuplot 脚本，再确认在隔离容器中执行。可预览 PNG，选择下载图像、数据、脚本和清单；绘图记录可随格式6项目包导出和恢复。

执行使用协议2 Linux Docker 镜像，默认不联网，以只读输入和受限容器运行；安装或升级时需按[实施记录](../development/v1.3.0/IMPLEMENTATION.md)重建并配置镜像摘要。首次使用绘图存储须明确确认创建扩展表。源码发布不包含模型、用户数据或安装包。

本轮对改动范围执行了真实容器、临时 PostgreSQL、真实模型合成数据、项目归档、旧 Gaia 图表、两种浏览器和隔离边界检查；详情与 Linux/WSL 适配范围见[验收记录](../test-records/v1.3.0/acceptance/20261109T003436Z/README.md)。自动测试和模型生成不保证任意科研数据或结论的正确性。
