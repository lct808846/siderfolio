# AstroAgent v0.4.0：查询结果可视化与可复现导出

发布日期：2026-10-28。包版本与 OpenAPI 版本为 `0.4.0`。本次为源码发布，提供 Git 标签、GitHub 自动源码归档及测试记录，不附带安装器。实际检查与外部限制见 [测试记录](../test-records/v0.4.0/README.md)。

**本版本按用户 2026-10-28“直接发布吧”的明确授权，带已记录的 SIMBAD 外部连接超时限制发布。** 该授权不将失败验收改为通过；离线测试、Ruff、依赖检查以及目标提交的主分支和标签 CI 仍为发布检查。

用户取得完整聊天响应后，可通过独立 `POST /api/v1/exports` 下载 ZIP。导出不构造 Agent、不读取模型密钥、不查询外部数据库。原有聊天请求、三工具预算和失败降级行为保留。

- 完整 JSON 快照、SIMBAD / ADS / Gaia 固定列 CSV、中文说明与逐文件 SHA-256 清单。
- 显式选择的 Gaia 自行散点图、视差直方图和观测颜色—星等图，使用完整交付行；记录参与/排除编号、原因、坐标、分箱与截断信息。
- 快照逐层拒绝未知字段，验证计数、状态、单位、来源关系、编号及现有统计/距离复算；保留失败与无匹配。
- 2 MiB 实际接收限制覆盖分块请求；最多12次查询、3张图，未压缩总字节与ZIP各16 MiB；进程内非阻塞锁，异常后释放。
- CSV 对危险文本添加前导单引号，长 source_id 始终保留精确 JSON 字符串；CSV编号采用明确的文本提示策略。
- PNG 为1200×900、150 DPI，使用DejaVu Sans和非交互Agg；增加Matplotlib运行依赖与可重复执行的HTTP验收脚本。

客户端快照的来源真实性未经认证，哈希不是来源签名。图表仅描述实际交付样本，不用于成员判定、年龄拟合或新的物理参数推断。视差保留负值/零值，颜色—星等图使用视星等且未校正消光；距离仍仅导出原查询明确启用的近似结果。

没有新增前端、会话、云存储、长期下载链接或安装器。自然语言中要求画图不会自动提交第二个导出请求，使用示例见 [README](../../README.md)。

## 验证与已知限制

离线测试347项通过、15项联网测试默认跳过，Ruff检查/格式与依赖检查通过；本机真实HTTP导出11/11通过。Gaia圆锥/精确源、ADS查询→导出及PNG视觉检查通过。最近一次完整联网重试为8/14通过、6项失败，原始报告保留在 [本次重试记录](../test-records/v0.4.0/live-export-tests/20261028T114710460235Z/report.json)。

独立SIMBAD查询和名称→Gaia链路仍返回 `simbad_timeout`；名称链路因未取得坐标而停止。三工具场景保留Gaia和ADS成功数据并返回 `partial`。这不证明远端维护或全球不可用；SIMBAD访问恢复后仍需补验这三条完整成功路径。

六个真实场景的ZIP下载和逐文件SHA-256核对均通过，失败查询在快照与清单中保留。导出成功不能替代数据库成功链路。临时验收服务均已退出、端口关闭。
