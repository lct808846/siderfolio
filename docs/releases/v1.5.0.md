# AstroAgent V1.5.0

本版支持 Docker Desktop + WSL2 部署网页、后端、PostgreSQL、Ollama 与内部绘图执行器；复用已有嵌入模型与离线 Qwen 权重，数据库和模型独立持久化，不自动迁移或覆盖原有科研数据。部署说明见[容器方案](../CONTAINER_DEPLOYMENT_V1.5.md)。

新增可选本地助手与会话命名。为保留科研原文，明示条件由有界规则逐字提取，模型仅建议任务类型；摘要选取原文片段，格式整理保留原文，不提供自由科学改写。自动命名失败保留规则标题，手动改名优先，重启不重放推理。CPU推理请求期限120秒，首轮命名额外等待最多60秒。

绘图入口整合到会话工作台，支持数据上传、方案审阅、隔离执行、PNG预览及选择下载。项目归档、来源关联、科研流程和侧栏交互统一布局；修复窄屏结果面板占错网格行导致操作按钮不可点击的问题。

按改动范围完成固定质量样本、原文保真、自动命名竞态、数据库256 MiB存储上限、项目完整归档恢复、科研流程失败后显式继续及双浏览器检查，原始失败与修复复验见[验收记录](../test-records/v1.5.0/remaining/20261113T003239Z/README.md)。标题仍有1条被拒绝，普通样本格式合格率97.7%、主题保留90.9%，符合测试前门槛；不将拒绝计作质量成功。模型与数据仍需用户核对，验收不保证任意科研文本的正确性。

限本机单用户部署。嵌入模型、密钥及初始化脚本仍有只读本机挂载；绘图任务不联网、非root、只读根、无密钥和Socket，并有资源/超时限制。但内部执行器本身拥有同一Docker守护进程的高权限，不等同于独立虚拟机隔离，不用于公网多用户或强对抗环境。GPU与跨机器部署未验收；Gaia联网按用户授权跳过，不宣称外部科研服务普遍可用。源码发布不附带模型、用户数据或安装包。

修复发布构建发现的开发依赖安全问题：更新Vite、Vitest及相关依赖，固定修复版传递依赖，并增加CI高危安全通告门槛。当次npm审计为0项已知漏洞；这不等于对操作系统和全部镜像完成安全认证。开发环境要求Node24和兼容的npm11，容器使用固定Node镜像。
