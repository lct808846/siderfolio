## 1. 交付范围

用户可以在项目内创建一项小规模 N 体模拟，审阅和确认初始条件，将任务提交给后台计算，关闭网页后再回来查看状态、图表及可下载的实验记录。任务支持取消和再次运行，每次运行有独立记录，支持比较两次实验的参数和结果。FastAPI 负责身份、参数校验、入队与查询，独立 Worker 负责执行计算。

V1.7 延续单 Agent。用户可直接填写结构化表单，也可由对话生成同一份参数草稿。自然语言含糊时，Agent 应标明缺项或追问，界面须区分用户输入与模板默认值。实际计算由用户在项目内确认，并选择 REBOUND 或 PeTar。科研流程页继续承载既有 SIMBAD、ADS、Gaia 等固定流程，计算任务作为项目内的独立入口。[固定科研流程范围](PROJECT_PLAN_V0.7.md)

| 本版交付 | 最小可用结果 |
| --- | --- |
| 科研任务中心 | 任务列表与详情、参数审阅、后台排队、状态查询、取消、重新运行 |
| N 体模拟 | 封闭系统的小规模点质量引力模拟，提供圆轨道双体验证模板和有限粒子初始条件表单 |
| 可视化 | 位置快照、轨迹与能量误差曲线，浏览器预览与选择下载 |
| 实验记录 | 保存实际输入、运行环境、诊断和产物，支持重跑及两次实验比较 |

首版用于建立实验流程和验证数值能力，支持孤立点质量系统。完整双星团研究仍需另行设计初始模型、外部环境、粒子规模、采样策略与收敛实验。HPC 调度、外部环境模型、恒星演化与大规模双星团模拟属于后续研究扩展。MCP 和 Multi-Agent 各自单独规划。

## 2. 使用路径与界面

1. 用户登录后在项目内打开「计算任务」，选择双体模板或录入粒子初始条件。对话生成的草稿也进入这一页面，按当前项目权限打开。
2. 审阅粒子数、质量、位置、速度、单位、积分参数、估算输出量和资源限制。提交时核对草稿版本和参数摘要。修改草稿后需要重新确认。
3. 页面显示等待、计算、正在取消、完成或中断等真实状态。排队时显示等待，运行时显示已输出快照数和最近一次更新时间。无法估计剩余时间时，显示实际进度信息。
4. 用户关闭标签页或刷新后，后台任务继续，回到项目即可恢复查看。失败页说明原因和处理方法。取消完成后可以复制参数创建一项新任务。
5. 成功后查看初始条件、版本、诊断和图表，选择下载原始数据或实验 ZIP。用户可在同一项目选两次运行，核对输入差异及目标指标。物理单位、参考系、诊断定义和采样网格相容时才提供直接叠图，其他情况并列展示并说明差异。

使用既有工作区导航、面板标题、主题与状态提示。桌面使用任务列表与详情，窄屏复用已有面板切换。颜色与文字共同表达状态，图表提供坐标单位、图例和实验来源。详情只呈现科研相关参数与可操作的错误信息，执行诊断按权限查看。[UI 设计规范](UI_DESIGN_SPEC.md)

## 3. 任务生命周期与接口

| 状态 | 含义与允许操作 |
| --- | --- |
| `draft` | 可修改的草稿，等待用户核对 |
| `queued` | 已确认的参数快照等待认领，可取消 |
| `running` | Worker 已认领且租约有效，可请求取消 |
| `cancelling` | 已记录取消请求，等待确认执行进程退出 |
| `succeeded` | 数据包和诊断通过格式与完整性检查，产物已发布 |
| `failed` | 参数预检、积分、资源限制或产物处理失败，保留原因 |
| `cancelled` | 未开始即取消，或已确认运行进程停止 |
| `interrupted` | Worker 重启或失联导致本次执行无法确认，保留记录供核查 |

- **提交**。同一项目和用户下按请求幂等键提交。同键同参返回原任务，同键异参返回冲突。确认与入队在同一事务完成，记录参数版本和实际完整输入。对话工具只生成草稿，确认接口要求当前登录人主动操作。
- **认领**。PostgreSQL 保存队列，Worker 用短事务原子认领任务，记录试次标识、执行代号、租约和心跳。队列可用 `FOR UPDATE SKIP LOCKED` 避免 Worker 同时认领锁定中的记录。提交、取消、配额占位和结果发布必须使用条件更新或等效事务保护。[PostgreSQL 锁定子句](https://www.postgresql.org/docs/current/sql-select.html#SQL-FOR-UPDATE-SHARE)
- **取消和重启**。排队取消直接结束。运行时先提交取消请求，再终止计算进程并确认退出。取消与成功竞争以服务端原子提交顺序为准，界面读取最终状态。API 重启时队列仍保存在 PostgreSQL，正在运行的 Worker 可继续执行。Worker 失联后，租约失效且未能核验结果时标记中断，废弃旧执行代号，阻止原 Worker 发布迟到结果。确认原进程退出后再清理临时文件并释放执行槽，平台硬超时负责兜底。
- **重跑**。从已有记录复制参数形成新草稿，须重新确认并获得新 ID，记录来源任务。取消、失败或中断不自动重跑。旧实验和图表保持原样，允许用户并列复核。

建议采用项目下的 `/api/v1/projects/{project_id}/compute-tasks` 资源，提供列表、创建和详情，另提供草稿更新、确认启动、取消、复制重跑，以及受权的产物列表和下载。前端按状态轮询，终态停止。实际接口发布前生成 OpenAPI 快照和 TypeScript 类型。所有请求按 V1.6 既有身份机制校验当前账号、项目和子资源，并对修改操作沿用 CSRF 防护。项目移除或账号停用时终止活动任务并撤销读取权限。后台网页不自动获得查看用户实验内容的权限。[V1.6 部署与身份说明](development/v1.6.0/OPERATIONS.md)

## 4. REBOUND 原型与数值契约

使用固定的 REBOUND 版本和 IAS15 积分器。首版采用牛顿引力、点质量、孤立边界和固定输出时刻，质量为正，初始位置和速度使用三维笛卡尔坐标。界面固定使用 `AU`、`yr`、`M_sun`，记录实际引力常量、积分设置及参考系。双体模板以质心坐标系保存完整状态。版本、依赖和参数在实施时锁定，随后由运行记录写入实际值。[REBOUND 文档](https://rebound.hanno-rein.de/) · [IAS15](https://rebound.hanno-rein.de/integrators/ias15/)

| 参数或限制 | 首版设计值 |
| --- | --- |
| 粒子输入 | 2–128 个，粒子 ID 唯一。质量、位置和速度须为有限数值，拒绝重复位置、非法或越界输入 |
| 输出采样 | 2–512 个时刻，含起始和结束；模拟时长大于零。实施时为物理量和时长固定合成样本验证过的上下限 |
| 资源上限 | 每次运行暂定 120 秒墙钟、512 MiB 内存、1 vCPU、32 MiB 产物。每用户最多 2 个排队、1 个运行，全局先运行 1 个。以上是待实测的初始配置值 |
| 运行边界 | 遇数值发散、非有限状态或模板规定的最小分离距离阈值即停止并说明。首版按固定规则终止近接/碰撞异常，按独立的墙钟超时兜底 |

双体模板先采用显式初始条件，无随机参数时记录种子为不适用。加入可选随机初始条件生成时，需同时保存生成器版本、种子和生成后的实际粒子表。显式记录是否使用软化和碰撞规则，并保证诊断与积分所用的势一致。浮点差异按科学误差阈值评价，文件哈希用于核对某次运行的产物完整性。

输出包括每个采样时刻的粒子位置和速度、质量、总机械能、总角动量及其偏差。能量诊断记录 `E(t) − E(0)`，分母 `|E(0)|` 高于预先固定的近零阈值时才展示相对误差。角动量同样报告绝对差并在初值适合时计算相对值。诊断记录使用的单位、阈值、样本数与最大偏差。能量误差异常须显式标注，失败与取消不能生成成功报告。轨迹、快照和误差图由数值产物派生，网页与导出图保持可核对的一致来源。

## 5. 存储、绘图与部署

- **记录与归档**。PostgreSQL 保存用户和项目归属、不可变输入快照、任务及执行记录、状态事件和产物清单。记录版本、镜像摘要、积分器与精度参数、实际粒子初值、单位、参考系、随机种子或不适用、时间戳、运行耗时和失败原因。任务成功后提供独立的带版本实验 ZIP，包含 `manifest.json`、输入 JSON、快照 CSV、诊断 CSV 与所选图表。清单列出成员类型、大小和 SHA-256。既有项目 ZIP 格式继续可用，界面和操作手册应说明本版计算实验用独立 ZIP 保存。
- **产物发布**。写入独立临时目录，核对大小、格式、路径及校验值后发布，事务提交前不提供下载。数据库更新失败时清理无引用产物。下载通过已经验证项目归属的后端接口读取受限路径。记录目录不可直接通过静态站点访问。备份需协调数据库与产物卷的一致性。
- **绘图**。优先复用既有表格预览、绘图服务和安全下载。首版由固定可信模板从受限快照或诊断数据产生图表，继续沿用隔离执行、资源上限和产物验证。绘图失败单独显示并提供重试，已提交的数值结果仍可查看和下载。[V1.3 绘图开发文档](PROJECT_PLAN_V1.3.md)
- **运行环境**。沿用现有 Compose，将内部 Worker 与 API 分离。Worker 的队列协调进程只使用完成任务所需的数据库权限和专用存储。模拟子进程在受限执行环境中运行固定程序，仅接收经校验数据，禁止网络，使用非 root、只读根目录、专用临时空间和硬资源限制，不继承数据库、邮件或模型密钥，不接触宿主机或 Docker 控制接口。计算功能关闭或 Worker 不可用时，现有科研工作区可以正常使用，计算入口明确提示状态。
- **升级**。以增量表和独立产物卷接入，保持现有任务、身份和数据契约。部署手册说明开关、健康检查、队列和磁盘监控、备份恢复与回退顺序。首次迁移和恢复在获授权的隔离环境执行，原部署的私有配置和数据卷保留。[整体容器化部署方案](CONTAINER_DEPLOYMENT_V1.5.md)

以下是原型验收设计。已执行的证据及限制见[增量验收与部署记录](test-records/v1.7.0/changed-parts/20261118T112200Z/README.md)。正式发布与日常数据库启用各自验收和授权。

- [ ] 从对话创建草稿和从表单创建草稿均可审阅。缺参要提示，未确认的草稿不进入队列；关闭或刷新网页后，状态与结果可恢复，API 请求不等待积分完成。
- [ ] 验证重复提交、并发认领、排队与运行中取消、取消与完成竞争、API/Worker 重启、任务超时、重跑与迟到结果。同一运行只发布一次成功结果。
- [ ] 两个账号相互尝试访问任务、状态、产物、取消、重跑及下载。验证项目约束、账号禁用、队列配额和执行隔离。超时及内存、输出超限后可清理并释放资源。
- [ ] 独立脚本以牛顿圆轨道解析值验证双体周期、间距、质心、能量和角动量。建议以无量纲相对误差 `10⁻⁶` 作为一轨周期、轨道间距及守恒量的原型验收初值，按初始间距归一化质心漂移。阈值与采样程序在运行前固化，保留实际偏差。另用固定小粒子样本检查收紧积分精度后的短程结果一致性及异常输入处理。
- [ ] 快照表、轨迹、误差图及下载包均溯源到对应运行。核对单位、读取字段、完整性、告警与图表一致性。同参重跑可在预设容差内再现核心指标，改变参数后可在页面追踪差异。
- [ ] 在授权的专用库演练备份、升级、Worker 关闭与恢复。回归原有认证、任务外的科研流程、聊天、RAG 及绘图。保留旧版验收记录和本次覆盖差异。
