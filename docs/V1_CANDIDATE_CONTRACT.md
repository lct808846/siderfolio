## 候选接口族

| 接口族 | 行为与兼容边界 |
| --- | --- |
| `/health`、`/docs`、`/openapi.json` | 保持既有入口；健康不证明所有外部服务或本机存储可用 |
| `POST /api/v1/chat` | 保留旧单次无状态语义；不会因关联自动读取本地文献 |
| `/api/v1/conversations`、`/{id}/turns` | 保留历史、显式发送、上下文和幂等；关联不改写旧ChatResponse |
| `/api/v1/exports`、轮次/快照产物与`artifacts` | 保留V0.4严格科学快照、JSON/CSV/PNG/ZIP及清单语义；预览缓存可过期 |
| `/api/v1/projects`及会话/快照/重跑/比较 | 保留既有修订、独立快照、直接工具重跑、来源及配额；新增关联计数 |
| `/workflow-templates`、项目`/workflows` | 两个固定模板，不执行任意代码、不构造模型；显式继续、成功检查点和中断不确定性 |
| 项目`/documents`及`/knowledge` | 本地文档、不可变文件版本、FTS词法检索、摘录、原文/提取预览及引用校验；不提供OCR、向量或模型全文回答 |
| 项目`/overview`、`/links` | 新增同项目`user_reference`、创建确认/幂等、只改备注、稳定分页和显式解绑；无外部查询 |
| 项目`/archive`与`/projects/import` | 默认导出格式4；格式1–4导入；旧版本不能读取格式4；显式旧格式导出需无不支持数据 |

字段类型、必填/可选及响应以已生成的 [OpenAPI](../frontend/openapi.json) 为机器接口候选快照，前端类型由它生成。生成不等于兼容性检查通过。

错误继续使用安全错误结构；关联不存在/越项目为404、修订/幂等/运行中冲突409、失效或无效输入422、越界413、服务不可用503。知识库上传后解析失败保留已创建记录及对应HTTP状态；HTTP成功不等于科学数据成功、流程无跳图或文献被全文正确解析。

## 数据与状态

- SQLite schema5新增 `project_links` / `project_link_requests`，升级前一致性备份，失败回滚，未知高版本拒绝写入。
- `ProjectLink.record_version=1`，只允许`user_reference`；目标为固定轮次、快照或流程运行，证据固定文档版本/位置/哈希。备注是用户文本，不能当作原文、测量或因果结论。
- 创建使用项目修订与请求UUID；同键同体返回原响应，并提供是否仍存在及当前修订；同键异体409。相同两端已有可用关联返回原记录，不能用重复创建改备注。
- PATCH只改备注，需要项目与关联修订。解除关联不删除两端数据；创建请求历史保留，重放不会重新创建已解绑记录。
- 目标删除、会话移出项目和文档删除记录永久失效标志；同名对象或原会话移回不自动复活旧关联。仅元数据缺失原文可在同哈希/固定位置恢复后重新核对，区别于删除失效。
- 流程关联运行整体；运行后续明确继续导致状态/摘要变化时显示“关联后更新”，不能猜测文献对应哪一步或覆盖旧尝试。
- 同一只读事务复用来源校验缓存，仍核对文件、提取文本及位置；缓存只在该请求内使用，不把过去校验当当前事实。

## 归档与来源

| 格式 | 固定成员 | 导出条件 |
| --- | --- | --- |
| 1 | manifest/project/conversations/snapshots四个JSON | 无流程、知识库或关联/操作历史 |
| 2 | 格式1 + `workflows.json` | 无知识库或关联/操作历史 |
| 3 | 格式2 + `knowledge.json` | 无关联及其操作历史 |
| 4 | 格式3 + `links.json` | V0.9默认；保留关联、失效、操作历史及身份映射 |

格式3/4区分完整与仅元数据；完整备份需显示原文数量/字节并确认，缺失或坏哈希拒绝声称完整。仅元数据不保存知识库原文件、提取文本及段落原文；引用和关联保留固定身份并标不可用。

统一32 MiB压缩、128 MiB实际解压、64 MiB单成员、唯一固定成员、路径/压缩方式、严格JSON、哈希、引用与事务检查。新项目导入重映射全部活动/软引用ID，保留原ID和 `imported_unverified`。哈希只验证包内一致性，不认证论文或数据库；导入不执行流程、检索、模型或远端查询。

## 资源与科学边界

保持原20项目/20会话/40轮、快照/流程/文档限制和全库256 MiB业务预算。新增每项目1000关联、3000创建请求记录；列表上限100，页面每次25。元数据、操作历史和ID映射均计入预算，不自动淘汰旧记录。

SIMBAD故障转哈佛镜像仍由现有工具决定并保留实际来源；Gaia位置候选不等于成员，统计只描述交付行，有条件近似距离不等于直接测量或贝叶斯估计。ADS保留书目/原摘要，不宣称全文；本地摘录不据词法命中证明用户命题。所有这些规则在V0.9仍待当前提交回归。

## 退出与变更

本轮只有实现代码、文档和待运行材料。真实公开文献的授权与独立标注、两个平台安装/恢复、旧API与格式兼容、真实HTTP/浏览器、检索评估、联网与目标提交/标签CI仍是发布前门槛。若候选字段或数据格式后续必须变化，应增加变更条目、旧样本回归和迁移步骤；不得用“候选冻结”替代这些证据。
