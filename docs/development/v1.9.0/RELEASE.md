# AstroAgent v1.9.0

V1.9.0 增加个人天文文献库、运行详情和固定科研评估框架。

- 从顶部栏的「文献管理」进入个人文献库，可搜索已保存的条目并整理标签和备注。用户可从 ADS 结果手动保存，也可在会话中明确指定条目后让助手保存，逐条查看入库回执。
- 会话和计算任务提供运行详情，便于核对工具调用、耗时及任务状态。模型报告用量时显示实际数据，配置价目表后可查看费用估算。
- 增加固定科研样例和评估脚本，便于后续对比查询通道与版本表现。
- 改进会话加载、切换和结果预览。 [实施说明](IMPLEMENTATION.md) · [Docker 升级说明](OPERATIONS.md)

本次先发布 V1.9.0 源码。功能、视觉和自动化测试待 V2.0 开发完成后一起执行。
