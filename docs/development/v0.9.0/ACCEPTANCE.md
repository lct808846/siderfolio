## 页面与关联

- [ ] 项目总览能看到会话轮次、快照、流程、文档与关联；从快照/流程去知识库选择固定证据后返回建立关联，原文与结果均可定位。
- [ ] 同项目三个目标类型均支持；外项目/不存在对象统一404，运行中冲突409，失效/坏哈希/位置不可用422。
- [ ] 确认窗口冻结精确两端、备注和修订；取消不创建。旧回答、sources、统计、测量和文献原文不被修改或发送给模型。
- [ ] 同键重放、异体冲突、同两端去重、旧备注不被重复创建覆盖、双修订PATCH和显式解绑符合契约；解绑后原请求重放不新建。
- [ ] 结果/流程/会话删除或移出、文档删除后失效状态保留；移回同一会话、上传同名文档不自动复活。无效关联不展示替代原文。
- [ ] 仅元数据缺失与真正删除区分；提供相同SHA-256且分段位置一致后，可重新核对固定原文，而非跳到新版本。
- [ ] 来源分类、原URL/UTC、文档版本/页行、流程版本、用户备注和未认证标记清楚；流程后续更新提示但不猜测科学关系。
- [ ] 列表按不可变ID稳定分页、过滤/游标/修订变化提示、100/1000/3000上限、预算与异常回滚核对。
- [ ] Chromium/Edge桌面与390像素窄屏、键盘、长文本、纯文本HTML、断线恢复、确认和下载人工核查截图。

## 固定材料与指标

[集成场景](integration_cases.json)在运行前写入。`scripts/verify_v09.py --run`使用合成文献和科研工具替身、临时SQLite与进程内HTTP；它不是TCP/浏览器或真实文献评估。V0.8的32条检索样本保持独立报告，不能据此宣称真实文库有效。

新增关联/恢复检查要求全部声明场景通过；跨项目拒绝率1.00、无效/删除原文误展示0、固定身份被静默改写0、同键额外创建0。真实公开文献的授权、人工标注、前五覆盖/拒答/原文回查阈值需在执行前固定，当前尚未填充或运行，不编造真实样本或成绩。

验收命令示例：

```powershell
conda activate agent
python scripts/verify_v09.py --run
python scripts/evaluate_knowledge.py --run
python scripts/run_tests.py
python scripts/run_frontend_checks.py
python scripts/run_frontend_checks.py --browser
```

另外做真实TCP、公开文献及两个平台安装/恢复；联网单独显式启用，旧模型测试可能有费用。记录到 `docs/test-records/v0.9.0/<类型>/<UTC时间>/`，含提交/环境/覆盖/失败/服务清理；不提交个人全文或凭证。测试和CI满足约定门槛、另有发布授权后再发布。
