# V0.8.0 发布前待验收清单

本页为发布前验收清单；部分检查已执行，结果与未完成事项见 [测试记录](../../test-records/v0.8.0/README.md)。下列未勾选项不能视为完整通过。用临时或独立数据库，避免操作个人文献。

## 网页手动验收

- [ ] 安装本版依赖并自行构建/启动后端与前端，确认版本0.8.0。打开项目“本地知识库”；上传、解析、检索、引用过程不调用模型或外部科研服务。
- [ ] PDF多页、空页、扫描页、混合失败页、加密、损坏、复杂布局、超页/文本限制均如实记录；不执行OCR，不把部分解析称全部可检索。
- [ ] Markdown含BOM、中英文本、CRLF/LF/CR、代码块、HTML、长行和不同标题层级，核对原始字节、行号、章节、分段及实际偏移；展示不执行脚本。
- [ ] 查看实际提取文本，核对原始SHA-256与整份下载；PDF按物理页预览，浏览器阻止受限预览时完整下载仍可用，不伪造精确高亮。
- [ ] 当前版本检索命中英文词、中文单字/双字/长词、大小写和精确短语；短词或大范围超限要求缩小，不静默丢弃候选；无命中返回 `insufficient_evidence`。
- [ ] 摘录只展示实际原文与出处，不按命中推断结论。每条引用可返回对应文件版本和页/行，坏哈希或位置不符明确失效。
- [ ] 重复同哈希上传提示已有文档，可明确创建独立记录；不同项目不泄露文档存在性。替换建立新版本，旧引用保持旧版本；显式恢复旧版本重新成为当前索引。
- [ ] 删除文档清理原文/所有版本/索引，引用失效并无原文摘录；说明空闲页、旧备份和已导出副本不等于安全擦除。项目删除与旧会话保留语义一致。
- [ ] 断线、刷新、重启、幂等原键、同键异体409、过期修订409、并发解析503可核对；没有自动重试。超额时不覆盖旧版本，不留下可搜索的半提交。
- [ ] Chromium/Edge桌面与390像素窄屏、键盘、中文输入、长文件名、隐私确认、错误、下载与预览均人工核查截图。

## 资源、归档与迁移

- [ ] Windows Job Object与Linux地址空间/CPU/输出限制、30秒超时终止、异常后进程/临时文件清理实测；无法实施保护则解析不可用，不能静默退回无限制模式。
- [ ] multipart实际字节、文件20 MiB、元数据32 KiB、额外开销64 KiB，项目100文档/200版本、PDF500页、20 MiB提取文本、25000分段、20 MiB候选扫描和业务配额限制验证。
- [ ] FTS5/unicode61/trigram及JSON支持与实际Python/SQLite版本留存；索引不可用时旧聊天/项目仍可用，显式重建可恢复；词法排名和稳定同分规则符合契约。
- [ ] schema3→4及更老库顺序升级，原数据不变，一致性备份、迁移故障回滚、高版本拒绝及独立目录恢复实测；个人库不用于试验。
- [ ] 格式1/2导入知识库为空；含知识库、历史引用或操作时拒绝省略后导出旧格式。
- [ ] 格式3六成员完整/仅元数据都往返核对，完整原文需显示数量/字节并确认，缺失原文不能声称完整；元数据包不含原文件、提取文本或段落原文，恢复后不可用。
- [ ] 元数据恢复后提供同哈希原文，恢复同版本身份与旧引用；提取/分段变化必须拒绝替换旧定位。导入记录标记未认证，所有身份重映射，不自动启动解析或外部请求。
- [ ] 坏哈希、非有限数、重复/未知成员、路径、压缩膨胀、错误归属/引用/位置、超限与事务故障，均拒绝且无部分导入。

## 预先固定的评估

`scripts/knowledge_eval/`含24条正例和8条无答案，来自人工合成中英标签，不是观测或真实文献。期望定位在运行前写入，不依赖本版检索结果生成。目标：正例前5覆盖率≥0.90、无答案拒答率=1.00、无效引用=0、合成小库P95≤2秒。正式结果应另注明机器、依赖、SQLite及样本版本；这个性能阈值不代表任意文库性能。

常用验收命令：

```powershell
conda activate agent
python -m pip install -e ".[dev]"
python scripts/evaluate_knowledge.py --run
python scripts/run_tests.py
python scripts/run_frontend_checks.py
python scripts/run_frontend_checks.py --browser
```

评估入口只有显式 `--run` 才会创建临时库并运行。32条Markdown检索样本不能代替 PDF、删除/旧引用、归档和资源限制等专项检查；这些检查的结果及适用范围见 [验收矩阵](../../test-records/v0.8.0/acceptance-matrix.md)。旧科研服务联网回归需另行启用，涉及旧模型测试时可能产生用量。

当次证据保存 `docs/test-records/v0.8.0/<类型>/<UTC时间>/`，不提交个人PDF、密钥或无权发布的原文。保留失败和缺口，检查服务清理；满足约定门槛并取得发布授权后再提交、打标签、发布。
