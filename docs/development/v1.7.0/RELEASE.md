# AstroAgent v1.7.0

V1.7.0 增加项目计算任务工作区，支持在 REBOUND 4.4.11 和 PeTar v1.0 之间选择。用户保存并确认初始条件后，独立计算服务后台执行，支持取消、复制重跑、对比轨迹与能量偏差，以及导出快照 CSV 和附校验清单的实验 ZIP。

- 初始条件支持圆轨道双体、层级三星与 Plummer 小星团预设，也可由开普勒轨道根数生成、导入 CSV 或 TSV，并转换到质心系。
- 科研空间支持个人默认空间和项目空间。工作台更新了会话侧栏、归档、外观设置与项目导航，项目会话可检索关联的本地文献片段。
- Gaia 圆锥查询与科研流程增加视差、自行和 G 波段星等筛选。查询结果仍按既有测量与候选源规则解释。
- 计算服务在无网络的非 root 容器中运行，每项任务最多使用 1 个 CPU 核、512 MiB 内存和 120 秒。旧 REBOUND 草稿、结果和校验值仍可读取。

计算入口支持 **2–128 个粒子的孤立点质量系统**。两组 PeTar 解析双体的最大相对周期偏差为 `1.96×10⁻⁷`。12 体 Plummer 样例完成运行，PeTar 的相对能量偏差为 `1.50×10⁻⁵`，页面显示了精度告警。 [计算增量验收](../../test-records/v1.7.0/changed-parts/20261121T092707Z/README.md)

升级或首次启用计算功能前见[操作说明](OPERATIONS.md)。本版通过 GitHub Release 提供源码。 [发布复验](../../test-records/v1.7.0/release/20261121T100026Z/README.md)
