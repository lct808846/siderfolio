# V1.7 计算任务部署与运行

V1.7.0 的计算部署沿用现有身份部署的 Compose 项目、私有配置和业务数据库。在原有 Compose 文件列表末尾追加 `-f compose.compute.yaml`。服务器开关 `COMPUTE_ENABLED` 默认为 `0`，此时项目计算页提示功能未启用。

## 启用

1. 在获准的数据库上核对当前身份部署，再以现有应用数据库角色连接同一 PostgreSQL 数据库。通过 `psql -v ON_ERROR_STOP=1 -f scripts/compute_schema.sql` 显式应用增量表。脚本在一个事务中添加计算表和索引，后台启动时没有自动迁移。验收使用独立数据库和独立 Compose 项目。
2. 在私有 Compose 环境文件中设置 `COMPUTE_ENABLED=1`。构建镜像后，用 `docker image inspect astroagent-compute-worker:1.7.0 --format '{{.Id}}'` 取得执行镜像 ID，作为 `COMPUTE_IMAGE_ID` 随部署传入。使用完整的文件组合与 `--profile compute` 更新 `backend`、`frontend` 和 `compute-worker`。Worker 健康检查依据共享目录心跳，功能验收使用独立数据。
3. 从项目进入「计算任务」，或从工作台的「N 体模拟」选择项目。在草稿的「模拟程序」中选择 REBOUND 或 PeTar，填写初始条件并保存，再核对并确认运行。程序选择随草稿、复制、确认和归档保存。使用模板或模型提取参数时，程序仍由用户选择。结果和运行记录归属当前账号及项目。

REBOUND 是默认程序。旧草稿和结果按 REBOUND 读取，原有草稿确认校验值可继续使用。PeTar 随新版计算 Worker 一同构建。现有 V1.7 数据库在更新程序时可直接使用，程序选择保存在已有的参数字段中。未就绪的程序仍可保存草稿，就绪后才可确认运行。

## 执行隔离和存储

- API 内的调度线程负责 PostgreSQL 和租约，独立 Worker 从专用共享卷接收已确认的数值参数。Worker 使用无网络、非 root、只读根目录、1 vCPU 和 512 MiB 内存的容器。每项执行由固定子程序运行，有 120 秒墙钟上限。PeTar 的中间文件位于 32 MiB 临时文件系统。取消或超时会终止本次任务的进程组，再清理中间文件。Worker 配置无需挂载数据库、邮件、模型配置或 Docker 接口。
- 同时最多一个运行实例。每个账号最多排队两项，最多保存 40 条任务记录。项目移除连同计算记录提交，调度器随后终止孤立的执行。账号停用后，调度器会取消其活动任务。
- 结果在格式检查后与完成状态一并提交到 PostgreSQL。专用卷只留交接中的参数、心跳和产物，调度器在确认结果或取消后清理。业务备份覆盖 PostgreSQL 中的计算表。恢复演练在隔离环境使用空的临时交接卷，租约到期的任务标为中断，可复制参数后重新确认。需迁移或恢复日常数据库时先取得明确授权。
- 计算记录独立导出。项目页面可下载原始快照 CSV，或下载含参数、快照、诊断、所选 SVG 和 SHA-256 清单的实验 ZIP。ZIP 中的位置快照使用页面的当前采样时刻。日常监控关注 Worker 健康状态、滞留的运行任务、PostgreSQL 表和备份占用，以及专用卷中超时未清理的记录。

## 数值契约

两种程序共享孤立牛顿引力、点质量、零软化和输入惯性坐标系。对外使用 AU、yr、M_sun 和 `G = 4π² AU³/(M_sun yr²)`。初始粒子间距须大于 `1e-5 AU`。双体模板两颗等质量粒子的初始间距为 1 AU，质心位于原点，对应解析周期为 1 yr。

- **REBOUND 4.4.11** 使用 IAS15，`epsilon=1e-9`。积分期间触及 `1e-5 AU` 近接阈值时停止。运行记录保留安装包校验值与积分参数。[V1.7 REBOUND 验收记录](../../test-records/v1.7.0/changed-parts/20261118T112200Z/README.md)
- **PeTar v1.0** 使用树算法、Hermite 积分和 SDAR，保留原生的近接正则化和弱扰动慢化算法。单核容器计算孤立点质量系统，恒星演化与外部势关闭。结果发布前校验每帧的粒子数、ID 和质量。[PeTar v1.0 文档](https://github.com/lwang-astro/PeTar/tree/v1.0)

PeTar 原生输出间隔需要二进制时间步。Worker 将时间和速度换算到原生单位，按同一比例调整引力常量，验证原生快照时刻和粒子 ID 后，再换算回界面单位。树步长取不超过快照间隔的 1/8 及初始最短两体动力学时间的 1/1024 的最大原生二进制时间步。变化半径使用 PeTar 的开普勒时间步设置。能量和角动量按换算后的快照计算。运行记录写入源码提交、原生时间单位与树步长。

两种程序均支持 2–128 个粒子、2–512 个含端点的等间距采样时刻。每颗粒子的质量范围为 `[1e-9, 1e6] M_sun`，各位置或速度分量的绝对值上限为 `1e6`，模拟时长范围为 `[1e-6, 1e4] yr`。相对误差仅在对应初值的绝对值或范数高于 `1e-12` 时计算。实验 ZIP 记录程序、版本、参数和诊断。镜像 ID 由部署时传入，未配置时为空。

PeTar 的页面实景、解析双体、非二进制采样、输入顺序和取消超时均已在独立环境复验。固定的 12 体 Plummer 样例触发了能量偏差告警。 [PeTar 增量验收记录](../../test-records/v1.7.0/changed-parts/20261121T092707Z/README.md)

## 停用和回退

停用前先取消所有活动任务并等候终态，随后将开关设为 `0` 并更新后端，最后停止 Worker。回退镜像时移除 `compose.compute.yaml` 并使用部署前的镜像版本。保留现有数据库和 Compose 数据卷，便于恢复到 V1.7。数据库或卷的清理另行授权。
