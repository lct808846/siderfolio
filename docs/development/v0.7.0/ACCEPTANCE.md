## 网页手动测试

由用户安排启动更新后的单worker后端和前端，按README操作，打开项目中的“科研流程”。新版本尚未构建，不能把旧 `dist/` 当成本版页面。

- [ ] 创建空项目与两种流程，创建/查看不访问SIMBAD、ADS、Gaia或模型；固定步骤和参数完整，取消确认不执行。
- [ ] 坐标Gaia：明确填写ICRS赤经/赤纬、半径、上限，分别选择质量筛选、距离开关和三种图。查看完整100行、字符串编号、单位、ADQL、来源时间、统计、截断及科学限制。
- [ ] 名称Gaia：SIMBAD实际返回坐标后才查Gaia；主站失败的哈佛镜像来源如实保留。无匹配、超时、坐标缺失均停止依赖步骤，不使用预设坐标。
- [ ] ADS：确认原始检索式、排序、偏移和篇数；核对原书目与原摘要、缺失标记和来源。查询无匹配为空表，查询失败不生成条目；不产生模型总结或全文阅读声明。
- [ ] CSV：Excel中中文、长摘要、负数和危险前缀内容正确显示；UTF-8 BOM、公式保护与长文本变更清单存在，JSON保留原值。与实际返回论文逐项对应。
- [ ] 下载ZIP、清单、证据CSV/JSON与PNG；核对长度/哈希，图片字节与ZIP中对应图片一致。数据不足跳图和导出部分完成均显示原因。
- [ ] 执行中断线后刷新，页面只读状态；使用原请求编号核对不会增加尝试。服务重启后为interrupted，继续需明确确认，不自动重放远端调用。
- [ ] 在桌面、390像素窄屏、键盘及长文本场景核对表单、三个面板、对话框、状态、错误与下载；字符串HTML不执行。

## 执行、恢复和存储

- [ ] 同一请求UUID/请求体：进行中202、结束后原操作加当前运行详情；不同体409；过期修订409，均不额外触发调用。
- [ ] 两个执行槽与旧聊天/重跑共用，第三项返回忙；同运行并发不重复执行，短事务不覆盖外部HTTP调用。
- [ ] 分别在每步调用前、远端返回后提交前、保存失败、重启时模拟故障；继续仅重试失败/中断步骤，保留历史；已确认的成功步骤不重新查询。
- [ ] 成功检查点的模板/软件/输入/上游摘要改变、输出或快照缺失、哈希错误时，拒绝继续并指引新建运行，禁止静默复用。
- [ ] 导出器忙、2 MiB请求边界、16 MiB文件/记录边界、存储不足或绘图异常时，不裁剪完整原始查询，已经保存的快照保留。
- [ ] 50运行、5尝试、20执行请求、20会话、100快照及256 MiB业务预算均拒绝超额，异常后预留与执行槽释放；无部分写入。
- [ ] 流程引用的快照删除409；删除流程后可删快照。运行中项目/相关实体删除或移动被拒绝，删除项目时明确包含流程与输出，保留会话。

## 归档与迁移

- [ ] 用真实旧库副本进行schema2→3（及schema1顺序迁移），核对原记录未变、一致性备份、迁移故障回滚；V0.6拒绝schema3，备份在独立目录可恢复。
- [ ] 旧格式1四成员包导入不含流程；无流程项目显式导出格式1；有流程时旧格式导出409，不能静默丢弃。
- [ ] 两种已完成/失败/中断流程各导出格式2再导入，核对固定五成员、所有文件/快照/操作/尝试/依赖及哈希。新ID逐层映射，来源保留；导入不访问外网或模型。
- [ ] 导入流程标记未认证并只读；复制参数后必须新建和确认才能执行。导入记录的running统一中断。
- [ ] 重复/未知成员、路径穿越、符号链接、加密、不支持压缩、坏JSON、非有限数、坏哈希、错误归属/依赖、伪造快照与文件、CSV公式或压缩膨胀一律拒绝；事务内无部分导入。
