# 用户消息与结果入口调整（待验收）

2026-11-02。根据用户提供的DeepSeek截图中圈出的用户提问区域实施，仅覆盖消息气泡、问题复制/编辑及结果面板触发规则。

## 用户提问

- 提问使用右对齐、按内容收缩的气泡；长问题仍保留换行并自动折行。轮次、时间与气泡对齐，回答仍从左侧开始。
- 气泡下提供独立复制和编辑SVG按钮，键盘与触屏可直接使用，不依赖悬停才出现。
- 复制使用用户主动点击后的浏览器剪贴板API，保留原始文字、换行和编号；失败明确提示手动复制，不显示虚假的成功状态。
- 编辑仅将原问题填入底部输入框，明确标记原轮次。确认发送后按既有规则新增一轮，保留原问题、回答、快照与来源，不回写或重新执行历史记录。
- 编辑前的未发送草稿在本页暂存，点击“取消编辑”恢复。生成中、正在创建/加载或断线请求待核对时禁止编辑，防止混淆待处理的问题；切换会话时清除编辑上下文。

## 结果栏

- 删除发送开始时自动展开的监听；只有所选轮次有完整响应且状态completed时自动展开。部分完成的科研查询仍属于已返回响应，会展示其实际降级说明。
- 用户已打开结果栏时发送新问题，不强制关闭；已有的“本轮正在查询，下方为此前结果”提示保留，以区分新旧数据。
- 全局顶部导航增加“结果栏”按钮，可独立打开/收起；按钮不放在对话面板内，因此窄屏或当前正显示其他面板时仍可访问。保留每轮“核查本轮结果与导出”的定位入口。
- 同一响应普通刷新不重复自动展开；手动开关、固定轮次链接和焦点返回规则继续保留。
