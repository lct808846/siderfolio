# 会话防重与侧栏管理（待验收）

2026-11-02。用户反馈连续点击“新建会话”产生多个空记录，并希望增加会话行菜单。按实际项目用途实现本地管理功能，不创建公开分享服务。

## 新建与发送

- 创建期间锁定新建按钮，仓储前端动作也检查创建状态，连续点击只发起一个创建请求。
- 当前会话仍为默认名称“新会话”、零轮次、没有本地轮次时，复用当前空会话。已命名或已有轮次的会话允许新建另一个会话。
- 创建返回成功后立即保留其ID；后续列表刷新失败不会丢弃已确认的创建，避免再次点击生成第二个空记录。
- 创建期间若用户已切换会话，旧请求不覆盖后来选中的会话，也不强制跳转。首次提问在创建/导航完成前锁定发送，并核对目标会话，避免把问题发到其他会话。
- 此防重范围为当前页面的连续操作，不是跨浏览器/跨标签的服务端幂等协议。网络断开导致创建结果不确定时应刷新列表核对，不把新请求视为原请求重放。

现有重复空会话不自动删除，可由用户使用多选管理整理。数据库/API/项目归档契约保持原样。

## 会话行菜单

| 操作 | 行为与边界 |
| --- | --- |
| 重命名 | 直接修改所选会话，携带该条metadata_revision；冲突或失败保持提示，不先切换当前会话 |
| 置顶/取消置顶 | 调整侧栏顺序，偏好只保存在当前浏览器；保存受限时明确提示，未将其当作数据库业务字段或项目归档数据 |
| 导出会话JSON | 用户确认后读取所选会话全部保存轮次、问题、回答、来源和结果，下载本地副本；读取前后核对会话版本与轮次状态，运行中或发生变化时拒绝本次导出 |
| 打开项目归档 | 进入已有项目管理入口；不默默建立项目关联 |
| 多选整理 | 支持勾选、全选和取消；删除前冻结待删除ID及名称并逐项展示确认 |
| 删除会话 | 用户确认后调用既有接口；成功项立即移出列表，失败项保留并显示原因，不自动重试；删掉当前会话时回到工作台 |

导出格式标识`astroagent-conversation`、版本1，包含导出时间、说明、会话元数据与完整保存轮次。它是可自行分享的JSON副本，可能含私人内容，不包含知识库原文件、数据库连接串或模型，不是项目ZIP，也没有新增导入承诺。导出不会调用回答模型、重跑查询或上传文件。

菜单使用页面外浮层以避免侧栏滚动裁剪；支持方向键、Home/End、Escape、Tab离开、外部点击关闭。操作弹窗使用原生dialog，删除/导出均需显式确认。触屏不依赖悬停显示操作按钮。
