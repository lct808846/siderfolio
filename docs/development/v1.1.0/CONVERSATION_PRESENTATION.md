# 会话呈现四项调整（待验收）

2026-11-02。按用户截图反馈，仅调整侧栏收起、自动结果面板、模型回答排版和自动标题。

后续反馈将结果自动展开时机改为完整响应返回后，并增加全局结果开关及用户问题气泡操作，最新行为见 [用户消息与结果入口](MESSAGE_ACTIONS.md)。

## 行为

1. 会话栏使用侧栏与左向箭头组合的专用SVG收起按钮，保留键盘焦点、标题提示和“收起会话列表”名称。
2. 桌面发起查询后展开结果栏，并提示正在处理；已有结果明确标记为此前保存内容。新的实际响应返回、切换到有保存响应的会话或选择某轮结果时自动展开；同一响应的普通刷新不会反复撑开用户已手动收起的面板。自动展开在桌面不抢输入焦点；小屏在返回响应后显示结果，并把焦点交给返回按钮。
3. 普通聊天与RAG模型回答使用Markdown排版，支持标题、段落、粗体、列表、引用、代码块和表格；宽表格可横向滚动。知识库原文及实际测量保留原值，保存与导出的回答仍是原始文本，不把格式化当作事实或引用验证。
4. 默认未改名的会话在首个问题被服务端接收、预留轮次的同一事务内命名：压缩空白、取首句并限制36字符，不另调模型。标题和元数据修订号持久化在PostgreSQL，后续问题不重新命名；手动名称和即使改回“新会话”的显式改名也保留。旧的默认未命名会话在下一次提交时使用其首轮保存问题补名，不在启动/浏览时批量改写历史。

## Markdown边界

锁定依赖为[markdown-it 15.0.3](https://markdown-it.github.io/markdown-it/)，使用内置类型。仅启用默认Markdown语法，禁用原始HTML、链接自动识别和字符美化。解析结果通过固定允许元素生成Vue节点，没有v-html、innerHTML或任意模型HTML插入。代码按文字显示，图片仅显示说明不发网络请求，链接只保留无凭证的HTTP(S)地址，明确点击后打开并隔离窗口/引用来源；原始PDF与文献摘录继续作为文本。

未加入公式渲染、任意插件、代码执行或额外问答模型。下载解析依赖使用D盘项目与D盘npm缓存；首次依赖安装报告旧Node22版本警告，随后使用本机Node24.22.1完成安装，无需安装新Node。
