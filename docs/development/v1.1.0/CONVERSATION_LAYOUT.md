# 对话优先布局（待验收）

2026-11-02。根据用户提供的DeepSeek与ChatGPT页面截图调整工作台布局。重点是增加中间对话的可用宽度和高度，同时保留原有字体、玻璃层次、科学提示及数据核查入口。

后续用户要求会话时自动展开右侧结果，最新行为以 [会话呈现调整](CONVERSATION_PRESENTATION.md)为准；空会话仍不长期占用结果区域。

## 布局与操作

- 默认显示224 CSS像素会话侧栏和伸展的对话主区域，结果栏默认收起，不再为暂无结果的面板长期预留400余像素。
- 对话头部的“会话”按钮可收起或展开会话栏。侧栏内也有收起按钮，继续保留新建、行菜单和多选管理。
- 点击“数据与导出”或某轮“核查本轮结果与导出”才显示结果面板；其计数只根据当前选中轮次实际返回的工具结果计算。URL指定轮次时继续定位并展开结果。
- 至少1440像素宽时，结果面板展开后与对话并列；981至1439像素时从右侧以抽屉形式展开；不超过980像素时，会话、对话和结果分别占据主区域，通过各自的关闭/展开按钮返回，避免强行挤出三栏。
- 会话栏和结果面板通过样式隐藏，保留组件实例；单纯收起展开不会丢弃会话菜单偏好、原结果或已生成图表产物，也不重新查询数据或调用模型。
- 缩减外框间距、全局导航及会话头部高度，移除主区域重复的改名/删除按钮，统一从会话行菜单操作。
- 输入框默认两行，随输入增长至144像素，再使用内部滚动；保留输入法、Enter发送、Shift+Enter换行、防重复发送及科研核查提示。
- 对话正文与输入区最大宽度1120像素，长文不横跨超宽屏；缩减轮次间距、回答上方留白、用户问题块和来源列表间距，保持字号可读。
- 空状态仅保留标题、说明和三个可点击的示例短按钮；点击示例仍只填入，不自动发送。

本次样式只作用于主查询工作台，其余项目、知识库、问答及流程工作区继续沿用原有断点。新增布局层最后导入以覆盖历史固定三栏规则。
