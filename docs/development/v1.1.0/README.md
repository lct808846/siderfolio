## 已写入的改动

| 部分 | 行为与目的 |
| --- | --- |
| WorkspaceHeader | 七个页面共用全局导航，具体项目显示五个功能入口；依路由标明位置，不额外请求数据库或伪造服务健康状态 |
| PanelSwitcher | 六个多栏工作区共用原生面板按钮，显示选中状态；原面板仍挂载，不因切换按钮重新创建 |
| 屏幕布局 | 大于1200 CSS像素保留并列阅读；小于等于1200改为单面板，避免三栏最小宽度相加超出屏幕；小于等于680允许头部换行 |
| 项目入口 | 无项目编号时默认展示项目列表；选择项目后进入记录，另有独立列表按钮；快照仍可进入结果面板 |
| 状态显示 | 设置页读取失败后不继续展示上次就绪状态；初始和失败状态显示“未确认”，模型/回答服务配置不冒充连通性验证 |
| 阅读层级 | 知识库、流程、问答与设置使用统一纸色和细线；来源、错误、单位、固定引用及发送确认仍展示 |
| 玻璃质感 | 根据用户反馈增加独立glass-surfaces.css：静态渐变背景、导航/宽屏侧栏的背景模糊、浮起输入区、圆角及柔和阴影；原文和表格保持清晰底色 |
| 字体层次 | 独立typography.css使用本机Noto Sans SC、Noto Serif SC、Bahnschrift与Cascadia Mono，分别处理界面、大标题、品牌和数据；统一字重/行距，保留系统回退 |
| 版本 | 后端、包元数据、前端锁文件、OpenAPI版本字段同步到开发版本；未更改业务接口结构、schema6或格式5 |

## 玻璃效果补充

用户认为初稿过于简陋，希望用高斯模糊和毛玻璃增加质感。本次仅修改前端样式与入口导入，沿用现有布局和功能。使用backdrop-filter模糊背景，不对正文应用filter:blur；宽屏侧栏透明度较高，正文面板保持接近实色。不支持背景滤镜时使用先定义的实色背景；1200 CSS像素及以下关闭大面积侧栏模糊，系统减少透明效果和强制颜色模式有对应覆盖。

没有新增依赖、网络素材或持续动画。未运行测试、构建、浏览器、截图评审或性能评估，不能据源码宣称视觉质量或低端设备性能已通过。既有Vite开发服务可加载新样式，用户可刷新页面查看。

## 字体精修

用户进一步要求提升字体质感。读取本机字体文件元数据，确认Noto Sans SC、Noto Serif SC、Bahnschrift、Cascadia Mono的内部名称与可变字重范围后，使用仅含local来源的字体规则及系统回退栈；未复制系统字体到项目、未安装或下载字体。大标题采用宋体层次，操作区与长文保持黑体，编号和代码等宽。数据表使用等宽数字，原文片段采用正文栈，避免将整段中文按代码字体显示。

本轮仅编辑样式和文档，没有运行测试、构建、浏览器或截图评审；本机字体文件存在不等于浏览器实际渲染已验收。其他平台的回退、文字换行、极长标题与窄屏布局仍待确认。
