# 会话模型切换

## 本机配置

服务端 `.env` 已切换到用户指定的 `https://maas.qianwenaiapi.com/compatible-mode/v1`。
密钥只保存在被 Git 忽略的服务端配置中，浏览器不接收密钥。
2026-11-08 读取该账户模型目录后，配置以下白名单：

| 界面名称 | 模型 ID |
| --- | --- |
| DeepSeek V4.1 Flash（默认） | `deepseek-v4.1-flash` |
| qwen3.8-max | `qwen3.8-max` |

`CHAT_MODELS` 配置 ID 和显示名，`DEEPSEEK_MODEL` 指定默认项。
该 MaaS 接口使用 `LLM_THINKING_PARAMETER=enable_thinking`；不沿用 DeepSeek 官方接口的 `thinking` 参数。
本机启动脚本仅对 `.env` 明确声明的模型配置覆盖继承的进程环境，避免旧密钥继续生效。

## 工作台行为

- 输入框下方可切换回答模型，选择按会话保存在当前浏览器；新草稿的选择沿用到首轮创建的会话。
- 模型控件固定宽度，工作台中靠输入区右侧摆放，以无底色、无边框的文字和箭头显示当前模型 ID。点击后先展开“模型 / 当前名称”单行菜单，再次点击进入同一浮层中的分组模型列表，支持搜索；悬停不会展开。保留选中勾选、方向键、Enter 和 Esc 操作，不显示各模型图标及说明页脚。千问的显示名称统一为 `qwen3.8-max`。
- 固定点击区域内的模型文字和箭头整体靠右，与圆形发送按钮保持 8px 间距及相同高度；发送按钮保留无障碍名称、悬停提示和处理状态，输入框聚焦描边改为较轻的强调。
- 每轮请求携带确定的模型 ID，并将实际模型保存在轮次 JSON 记录中；无需更改数据库表结构。
- 切换模型不会创建会话、清空消息或删除历史。历史准备仍按原会话读取，不按模型过滤。
- 现有上下文限制继续生效：最多最近 6 轮有回答的历史，并遵守字节预算；省略情况保留在上下文记录中。
- 发送过程中禁用模型切换；断线重试固定原模型及原请求编号。不同模型不能复用同一个请求编号。
- 服务端只允许白名单中的模型。未携带模型字段的旧客户端继续使用默认模型，旧请求摘要保持兼容。

## 文献问答

文献问答也可选择回答模型。预览记录固定所选模型和指纹；切换后需要重新预览确认。
已选文档及历史问答不因模型切换而清空，生成仍需原有的显式确认。
