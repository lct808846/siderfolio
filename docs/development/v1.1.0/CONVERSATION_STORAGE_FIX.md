# 会话创建失败修正（待验收）

2026-11-02。用户截图显示“本地会话存储不可用，结果未确认保存”。本机只读排查中，健康、设置及会话列表均返回200，数据库为ready；既有服务访问日志记录多次创建会话POST返回503，说明连接与列表读取成功不足以证明写入可用。

## 原因与修正

`ConversationRepository.create`仍使用SQLite具名占位符`:id`等并传入字典；PostgreSQL适配层仅转换问号位置占位符，导致新建语句无法执行。现改为显式六列、问号位置占位符及对应参数元组，两种仓储可分别采用原有参数绑定，不拼接用户标题。未修改表结构或迁移数据。

前端`recover`此前只在有当前会话ID时刷新，第一次创建失败后按钮无效。现无论是否有当前会话，均显式读取会话列表，成功后清除旧错误，失败继续显示错误；不创建会话或重发问题。

补充PostgreSQL会话创建/读取/改名/删除及特殊字符参数绑定的隔离回归源文件，以及无当前会话时刷新成功/失败的前端用例。按用户开发约定未运行这些用例、测试套件或构建，未调用模型、Gaia或其他科研服务。

本次重启后端以加载修复，读取健康、配置与列表只用于确认服务运行，不代表创建/保存链路或完整版本验收通过。未向日常数据库写入验收会话；历史验收记录不覆盖本次修正。
