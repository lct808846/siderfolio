# V1.1 发布前待验收

本清单尚未执行。由用户安排验收时，在隔离数据中运行检查并另存版本、提交、环境、命令、时间和结果，不覆写V1.0历史记录。

## 页面与导航

- [ ] 查询、会话、项目记录、来源关联、科研流程、知识库、文献问答和设置页可直接打开/刷新；全局与项目导航的选中状态准确，文档和流程详情仍能返回对应项目入口。
- [ ] 以1440、1201、1200、1024、768、681、680、390及320 CSS像素宽度检查布局，并覆盖浏览器缩放和较低窗口高度。并列/单面板切换均能访问全部功能，页面不出现无法触及的横向内容。
- [ ] 单面板切换保持已输入问题、文档选择和查询状态；切换面板不自动发送问题、构建索引或调用回答服务。
- [ ] 项目列表、新建/导入、项目记录、快照结果可分别访问；无项目、读取失败、长项目名与超长文献标题不阻塞导航。
- [ ] 仅用键盘完成导航、面板切换、输入和原有确认弹窗；可见焦点、选中提示、输入法、屏幕阅读和减少动态效果均核对。

## 数据、发送与故障状态

- [ ] 旧会话、SIMBAD/ADS/Gaia结果、来源、单位、图表、导出、快照比较、流程历史和项目包恢复可核对；明确真实网络服务的执行范围与费用。
- [ ] 知识库原文件、页码/行号、保留版本、失效引用和缺失数据清楚展示；表格与长原文可滚动。
- [ ] RAG预览和取消不发送回答；确认后只发送预览中列明内容。单面板可完成问题→证据预览→确认→回答→原文回查。
- [ ] 设置初始状态、读取中、成功、失败、成功后刷新失败分别核对。失败后不展示旧就绪结论；模型配置与实际推理/连通性区分，初始化仍需确认。

## 工程与交付

- [ ] 按项目既有流程运行前端类型、lint、单元、构建、接口一致性和浏览器检查，并回归后端、PostgreSQL及归档相关约定。涉及导航和面板的新行为在原有自动检查中覆盖。
- [ ] 在真实运行环境保存代表性截图并评审纸色/对比度/长文本/各状态；未截图前不声称视觉完成验证。
- [ ] 核对本机字体实际加载和缺失时的系统回退，检查中英文混排、大标题字重、代码/编号及数值对齐；窄屏长标题、输入法和长段原文不被截断。
- [ ] 核对玻璃导航、侧栏、输入区和弹窗背景，确保文字/表格/原文未模糊。检查滚动与弹窗性能、1200像素断点、不支持背景滤镜、减少透明效果和强制颜色模式；实色回退后仍能识别选中状态与焦点。
- [ ] 确定正式版本号后同步包、锁文件、界面与接口版本；单独记录最终提交/CI、跳过项和已知限制。开发版本不当作稳定发布。

Gaia旧失败、V1.0的检索评估及其样本局限继续独立保留；任何一次历史发布例外不等于本轮全量通过。
