## 已写入的改进

### 单词与编号的保守准入

对单个 ASCII 英文词、紧凑编号、类似“字母前缀 + 数字”的目录编号及纯标点输入，若词法检索没有在本次文档范围找到直接匹配，不启动语义近邻检索。预览返回 `no_results`、`semantic_status=literal_query_unmatched`，不填入可发送证据，并提示核对写法或补充完整问题。已有的无证据生成拒绝保持生效。

完整自然语言问题和中文问题仍允许纯语义检索。规则不识别评估问题、没有按问题 ID 加特判，也没有修改原 0.65 距离阈值、语料、分母或通过门槛。它解决的是孤立词/编号的歧义风险，不是通用可回答性检测。

代价是：单个英文词的同义词检索、编号的不同拼写形式可能需要改写成完整问题。字面未匹配不是“已证明文献没有答案”。完整自然语言的无答案问题仍可能误召回，必须在独立负例上继续验收，不能据此关闭通用科学忠实度问题。

### 同一项目重复问题的有界缓存

仅缓存问题向量，不缓存候选片段、原文、回答或发送确认；仍重新执行当前项目、版本、来源和原文检查。键包含项目 ID、固定模型哈希、维度及问题 SHA-256，不保存明文问题。默认最多 32 项、存活 300 秒，LRU 淘汰；读取不延长存活时间。向量只驻留本进程内存，重启即清空。

每次命中前仍核对实际模型文件身份，不能借缓存掩盖文件缺失、被替换或损坏。不同项目、模型或维度不共用条目。缓存未命中仍使用既有受限嵌入子进程，不扩大 120 秒 / 3 GiB 保护，不驻留模型进程。

配置项为 `ASTROAGENT_RAG_QUERY_CACHE_SIZE`（0 可关闭，最大 128）和 `ASTROAGENT_RAG_QUERY_CACHE_SECONDS`（默认 300，最大 900）。只对同一问题的重复预览预期减少重复嵌入，首次或新问题的冷启动仍存在，真实收益待计时复验。

### 页面与记录

页面增加检索已等待秒数、字面准入拒绝原因和向量复用提示，拒绝后继续禁止无证据生成。缓存命中不跳过文献的新鲜度核对。

新预览记录 `RetrievalTrace.version=pg-rrf-v2`，新增可空的 `embedding_cache_hit`。旧记录默认仍为 `pg-rrf-v1`、缓存命中未知，不把旧结果改记成运行过新规则。数据库 schema6 和格式5的八个成员不变；新代码可读旧 trace，旧代码未声明支持新 trace。OpenAPI 与前端类型已同步，但本轮未运行契约比较或类型检查。
