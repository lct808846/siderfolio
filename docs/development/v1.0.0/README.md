## 执行边界

仅执行源码/文档读取与编辑、保存原始工作区副本、Ruff源码格式化、OpenAPI/TypeScript生成和官方接口文档检索。代码生成未运行应用lifespan，不连接数据库或启动服务。

没有运行pytest、lint、依赖/类型检查、前端测试/构建、浏览器、评估、Gaia或其他科研服务请求、模型调用、模型下载、数据库连接/初始化/迁移、备份/恢复、CI、提交、推送、标签或Release。没有安装依赖或改写个人.env、SQLite、PostgreSQL或模型目录。没有创建本版通过报告。

本轮没有为Gaia超时确定根因或实施缺乏证据的服务替换；新增的诊断工具尚未运行。旧版7项超时记录仍属旧版，V0.9的带限制发布授权不自动用于V1.0。

## 验收层次不能混用

- 旧后端/浏览器测试显式使用临时SQLite契约替身，禁止继承日常PG连接；这是旧行为回归，不能证明PostgreSQL运行时通过。
- 新 `tests/test_rag_postgres.py` 需要独立本机测试维护库、显式开关及随机新数据库。模型和嵌入仍是合成替身，不能证明实际模型效果、资源适配或真实模型隐私行为。本轮未运行。
- 新CI的PostgreSQL任务只写了配置，未触发；旧CI或旧测试结果不代表这些变更通过。
- 真实嵌入、重启/中断/并发、迁移故障、平台安装恢复、真实TCP/浏览器、独立文献/生成评估、费用明确的真实模型与三服务均待验收。文献许可、独立标注与阈值未填充的部分明确保留，不伪造样本。
