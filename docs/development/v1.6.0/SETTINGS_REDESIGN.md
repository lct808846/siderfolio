## 布局与入口

- 本地助手页面的“模型与开关设置”直接进入对应分类。
- 设置侧栏提供账号安全入口与已完成 MFA 的管理员控制台入口，沿用原有权限限制，不调整认证逻辑。
- 宽屏内容最大宽度 800px；≤680px 分类横向排列，正文独立滚动。开关使用原生 checkbox 与 switch 语义，遵循减少动态效果设置。

## 状态读取与错误提示修复（2026-11-15 后续）

运行容器中的 setup/status 使用兼容 SQL 连接查询 pg_extension。原查询将 vector 写在 SQL 字符串字面量中，私有命名空间的兼容层会把它误改为 public.vector，查不到扩展后对空结果取值，最终被连接上下文包装为 conversation_storage_unavailable。改为绑定 extname 参数，避免类型名限定逻辑修改扩展名称；不调整账号隔离、数据库内容或 API 返回契约。

设置页不再把状态读取失败解释为会话结果保存失败。连接中断和存储读取错误使用针对设置读取的提示。新增可复用 StatusNotice，统一设置、本地助手和模型列表的错误显示：柔和背景、完整圆角边框、状态图标、标题、说明与重试操作；窄屏按钮换行。管理员控制台入口悬停与键盘焦点明确去除下划线。

已构建前后端容器，前端内置类型检查和生产打包完成；未运行自动测试或浏览器验收。前端资源为 index-RjHs4qLq.js、index-BwzDXMOb.css。本次更新 frontend 与 backend，保留既有配置和数据卷。

恢复码仅在当次绑定后显示，关闭弹窗后仍可在当前设置页重新打开保存，明确保存或离开设置页后不持久化；密码、验证码和未确认密钥在弹窗关闭后从前端状态清除。

接口契约已从实际 OpenAPI 生成并同步 TypeScript；本机 Python 无依赖，生成过程改用现有镜像依赖、只读源码挂载和临时缓存目录，无网络、无数据库连接。前后端生产构建完成，前端产物 index-CUbrsEWo.js、index-DMkiT8ub.css。按用户要求更新相关容器，仅进行启动健康检查，不运行自动测试或浏览器验收，不操作真实账号的 MFA 设置。
