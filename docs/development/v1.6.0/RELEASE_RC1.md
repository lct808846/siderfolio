# AstroAgent v1.6.0-rc.1 候选源码版

2026-11-16。Python 包版本为 `1.6.0rc1`，前端和应用容器标签为 `1.6.0-rc.1`。本版提供源码，不附安装器、模型、用户数据库或私有配置；属于本机部署候选版，不标为生产稳定版。

## 变化

- 邮箱激活、登录、密码恢复、CSRF、按账号独立业务空间及 MFA 管理边界；保留真实操作确认、任务撤销和审计。
- 个人资料、用户名、头像上传/移除和账号私域统计。头像重新编码、限制输入字节及总像素，快速更新不复用同秒缓存地址；统计排除未完成/跳过的任务，并明确与服务商账单不同。
- 设置分类、侧栏账号菜单、逐浏览器退出、扫码绑定及恢复码、跨标签页激活与登录衔接；共享布局、错误提示及桌面/窄屏阅读调整。
- 管理员可配置多个模型服务商、目录、默认模型及 OpenAI Chat/Responses、Anthropic、Gemini 协议。密钥只加密保存在服务端，地址/协议变化需重填密钥，过期配置修订拒绝写入。
- 延续 Docker Desktop + WSL2 部署及原绘图限制：任务不联网、非 root、只读文件系统、无密钥和 Socket，具有资源上限及超时；数据库、科研文件和模型分别保留。

## 验证

按用户要求，仅对后续改动进行增量验收。最新个人资料及相关界面记录中，34 项离线后端、39 项独立 PostgreSQL、40 项前端单元和 76 项双浏览器用例最终通过。初始失败、修复、测试适配和凭据日志脱敏均保留，见[最新记录](../../test-records/v1.6.0/changed-parts/20261116T071217Z/README.md)。此前身份/服务商等改动的范围见[前一轮记录](../../test-records/v1.6.0/changed-parts/20261115T074824Z/README.md)，不把跨轮重复检查累加为独立功能总数。

发布准备只调整版本、生成契约及说明，并核对与已验收功能源码的对应。最终发布应绑定同一个提交的 main CI、标签 CI 与候选 Release；以远端检查结果和发布页为准，不将准备中的状态写成已发布成功。

首次远程 main 检查中，前端和离线后端通过，PostgreSQL 中 8 项文献问答安全用例失败。原因是旧用例仍替换 `openai.OpenAI`，而新版数据库夹具已经使用统一模型适配器，失败注入没有生效。现将替身接到 `astroagent.model_client.chat_model`，保留全部引用、正文拒绝及失败状态断言，并额外要求替身恰好被调用一次；不修改业务实现或降低安全标准。首次失败见[远程运行](https://github.com/lct808846/astroagent/actions/runs/43831272914)，发布须等待修正提交重新通过检查。

## 使用与限制

先阅读[操作说明](OPERATIONS.md)，准备独立私有身份、邮件和科研服务配置。没有默认账号或默认管理员。升级前保留已有配置、数据库卷、科研文件、认证密钥及模型；旧数据认领、清空或恢复需要另外明确确认，不由构建或发布隐式执行。

- 本次不重复未改动的真实天文查询、科研生成质量、模型计费/额度及真实 SMTP 发送。Gemini 等外部服务的余额或权限问题不会因发布自动恢复。
- 当前邮箱继续入口会区分注册/激活状态；当前默认会话长时间持久并续期。不要把旧版“无账号枚举”或“固定短绝对寿命”当作当前属性。
- 管理员登录必须完成 MFA；模型配置免五分钟再次认证，其他账号管理操作仍保留。设置页仅向已完成 MFA 的管理员显示控制台入口，普通账号不能越权。
- Docker 内部执行器仍有同一守护进程的高权限，不能等同独立虚拟机或强对抗隔离；不要把 Socket 挂给对外后端或任务容器。
- 未认证公网 HTTPS、多机/GPU、大规模多用户承载、全部浏览器扩展或完整无障碍标准。科研结果必须核对来源，位置候选源和模型解释不是成员判定或科学结论。
