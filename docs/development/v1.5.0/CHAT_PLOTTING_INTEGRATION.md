# V1.5 聊天工作台内的科研绘图

2026-11-11。根据用户要求，把科研绘图融合进查询工作台，并删除顶部打开的独立页面。

## 入口和操作

- 删除全局导航的“科研绘图”链接及 `PlotLanding.vue` 页面。旧 `/plotting` 与项目绘图地址仅用于兼容跳转，实际呈现查询工作台。
- 聊天框底部新增带图标的“科研绘图”切换按钮；绘图模式直接使用原输入框填写需求，发送操作改为“生成绘图方案”。普通聊天草稿和绘图草稿分别保存，绘图草稿按当前会话区分。
- 在当前工作区选择或新建保存项目，选择本会话的成功 Gaia 查询并载入，或上传 CSV/TSV。上传绘图数据和普通聊天附件分开，避免误发到聊天模型。
- 原有绘图数据、方案、运行、审阅、明确执行、图像预览及选择下载复用同一实现，在工作台内部显示。生成方案不会自动执行脚本。
- 查询结果的“用本轮结果绘图”、项目中的数据绘图链接和原有快照/数据集链接转入工作台；原始项目、轮次、快照与查询序号保留。
- 绘图时暂时隐藏普通查询结果栏；返回聊天恢复原有结果展开状态。模式切换保留当前绘图界面及草稿，不创建空会话，不移动原有会话，不重新执行科学查询。

## 实施与边界

新增 `WorkbenchPlot.vue`，把项目选择与会话来源选择接入工作台；`PlotWorkspace.vue` 支持内嵌及共享输入，保持服务端不可变来源数据与请求编号机制。不改后端接口、数据表或历史科研记录。

前端构建包含 Vue/TypeScript 编译。首次构建发现旧地址重定向参数的类型不兼容，已修正后构建通过。按开发期约定，本轮未运行额外测试套件、浏览器验收、模型推理或科研联网查询；需发布前验收模式切换、来源导入、上传、方案审阅/执行及下载的完整链路。
