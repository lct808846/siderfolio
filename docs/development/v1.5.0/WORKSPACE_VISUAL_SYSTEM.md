# V1.5 页面一致性与视觉规范

2026-11-10。覆盖查询工作台、项目归档、来源关联、科研流程、科研绘图入口及工作区、本地知识库、文献问答、本机设置与本地助手。

## 共用规则

- 统一使用 `frontend/src/workspace-theme.css` 中的颜色、间距、圆角及表面变量。延续深绿导航，以灰白阅读面为主，侧栏使用轻度半透明；危险状态、警告状态与选中状态分别有明确颜色。
- 外框间距10px、移动端6px；共用56px导航高度和60px内容标题栏，移动端标题栏56px。具体科研页面按任务保留所需的列宽与布局。
- `WorkspacePaneHeader.vue` 提供统一标题、项目副标题和操作区。知识库、来源关联、科研流程、文献问答、本机设置、本地助手与绘图入口复用；工作台与绘图现有工具栏按相同尺寸规范呈现。
- 正文保留本地中文字体与清晰阅读行距；内容标题采用17px界面字体，章节使用16–20px层级；等宽字体用于数据、编号与脚本。空白起始页保留克制的衬线标题。
- 按钮共用36px基准高度与9px圆角；表单控件共用40px高度、边框、占位文字和焦点样式。图标按钮、发送按钮按功能保留专用尺寸；模型选择仍无外围边框。
- 表格表头、行距、悬停、等宽数据与滚动条统一；菜单、弹窗、状态标签、危险提示及处理中提示使用共用规则。
- 设置页用章节分隔线组织内容，减少卡片套卡片；原始证据和模型解释保持清晰分区。
- 窄屏右侧结果层对齐当前内容网格，不再依赖固定顶部像素值；导航换行后保持内容起始位置一致。绘图主区固定在内容网格列，避免浮动侧栏移出文档流后挤入零宽列。

## 保留的行为

本轮只调整界面结构与样式，不改变科研查询、模型选择、来源与引用、绘图执行确认、数据库、密钥或历史数据。原有侧栏动画、会话独立展开状态与减少动态效果偏好保留。

## 交付边界

前端容器构建包含Vue/TypeScript编译。按用户开发期约定，不额外运行浏览器、联网查询或测试套件；桌面/窄屏实景及真实科研内容的视觉验收待发布前进行。构建成功不等同于视觉验收通过。
