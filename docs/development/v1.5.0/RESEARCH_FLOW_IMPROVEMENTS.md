# V1.5 科研流程与绘图可用性改进

2026-11-10，根据当天 Edge 实测反馈，处理用户指定的五项问题。版本仍为 1.5 开发版，无新标签或正式发布。

## 改进范围

1. 全局导航新增“科研绘图”入口 `/plotting`；说明快速图表、自定义绘图和固定科研流程的用途。项目记录页也增加数据绘图快捷入口，绘图空页面可直接选择数据来源。
2. 成功且有数据的 Gaia 结果顶部提供“用本轮结果绘图”和“快速图表”。选择已有项目或新建项目后，服务端从已保存的完整轮次构造不可变来源副本并生成数据集，不重复访问 Gaia、不发送模型请求、不移动原会话；保留单位、缺失信息、长编号、原查询和来源时间。快照结果则直接进入所属项目并携带查询序号。数据导入使用稳定请求编号，失败后不自动重复模型或脚本调用。
3. 超时/错误明确显示“未取得”“不适用”，隐藏空交付表，禁止使用失败结果绘图；正常零匹配仍单独显示“条件下无匹配”。固定流程保留检查点和手动继续。Gaia 默认读取超时由 20 秒调整到 45 秒，连接等待最多 10 秒，显式自定义读取设置可覆盖；当前容器设置同步调整到 45 秒。不承诺远端超时已经消除。
4. 科研流程左侧保留历史列表，新建参数表移入中央；未创建运行时不占用右侧空结果区。已保存参数和执行确认以名称、单位和值呈现，原始 JSON 收入详情。绘图坐标轴也按横轴/纵轴展示；已完成运行的长脚本默认折叠，待执行方案仍展开供审阅。
5. 绘图新增图片宽度（1200–2400 px）、基础字号（10–18 pt）、轴名称/单位及点标注设置。默认不标注长 ID，可选原始数据行号；完整编号仍在数据表。设置记录到方案请求并传入模型，要求标签避让、图注计数、单位、合理留白及 PNG/PDF 输出。模型生成的实际脚本继续供审阅，不静默修改已确认脚本或历史图形，也不自动重绘旧图。生成质量仍需人工核查。

## 数据与兼容性

- 新增 `PUT /api/v1/projects/{project_id}/plotting/datasets/{dataset_id}/turn`。只接受轮次标识与查询序号，不接受浏览器提供的测量行。
- 会话来源以现有完整 Snapshot 契约冻结在数据集的原始来源字节中，可随已有格式6项目归档及绘图 ZIP 导出；无需新增数据库表或迁移。
- `PlotPlanRequest.appearance` 有默认值，原有调用可省略；OpenAPI/TypeScript 契约同步生成。
- 原有失败流程、科研项目、会话和图形保留；此次不重新推理、查询或生成科研成果。
