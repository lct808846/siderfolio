## 接口与资源边界

`/api/v1/local-assistant` 提供 GET 状态；`/probe`、`/initialize`、`/clear` 为带明确 JSON 请求的 POST；`/preferences` 为带修订号的 PUT。`PUT /jobs/{UUID}` 提交显式任务，`GET` 同路径核对状态；相同请求编号和不同内容冲突，不自动重发推理。会话下 `/local-title` 读取自动命名状态，`PUT /title-suggestions/{UUID}` 请求手动标题建议。实际契约以 `frontend/openapi.json` 为准。

- 本机地址固定为服务端数字回环 HTTP 地址；不接受前端URL、代理继承或重定向。每次生成先比对模型名称与固定摘要，拒绝云路由；不会拉取缺失模型。
- 一次推理，最多2个排队任务（可配置0–4），排队的手动任务优先；不抢占已运行任务。另有最多20个短命名记录调度槽。队满自动命名记录 skipped，手动任务返回忙。
- 手动原文至多4000字符且4 KiB；自动标题至多2000字符且4 KiB。回复128 KiB、生成上下文8192，提取至多1200输出token、其他任务700，默认120秒总请求期限（2026-11-13 CPU验收调整；首轮命名额外等待仍不超过60秒）、连接2秒、4线程。不是速度承诺。
- 标题严格 JSON、4–80字符、单行纯文本，目标4–20字符；拒绝部分指令式标题、陌生已识别天体编号和新增数值。摘要拒绝新增数值/已识别编号，格式改写还要求数值集合保留；均不能证明语义无遗漏、单位关系或科学正确。
- 条件值使用字符串和逐字证据，source_id 保持完整字符串；相对年份不能转换，缺单位的坐标/半径需澄清。歧义项为null，不以模型置信度代替校验。

## 数据与恢复

核心 schema 保持6。首次明确确认后创建 `local_assistant_meta`、`local_assistant_tasks`，扩展版本1；不自动升级旧库或覆盖不兼容表。任务元数据总量计入原256 MiB业务预算，运行或排队任务每条额外预留4 KiB供终态元数据及标题更新使用；最多500条，清理操作需确认。
