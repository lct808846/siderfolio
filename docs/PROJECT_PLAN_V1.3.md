# AstroAgent V1.3 开发文档：模型调用 Python 与 Gnuplot 绘图

**日期：** 2026-11-08  
**状态：** 2026-11-09 已完成本轮改动范围的本机验收，实际覆盖及限制见[验收记录](test-records/v1.3.0/acceptance/20261109T003436Z/README.md)；远程发布状态以 GitHub 为准。
**目标版本：** `1.3.0`  
**编写时基线：** 本地 `v1.1.0` 标签，工作区 HEAD `cc00e3b`；V1.2 是否存在及其内容尚未确认，实施前重新核查，不将 V1.2 描述为已发布。  
**目标：** 用户以自然语言提出绘图需求，模型调用 Python 或 Gnuplot 完成绘图，在网页查看结果，并选择要保存的图片、数据和可复现脚本。

本版在现有 Gaia 三种固定图与 ZIP 导出基础上扩展，不把既有固定图功能表述为已支持模型自由绘图。原有查询、科学计算、数据来源、RAG、项目和导出协议继续兼容。

## 1. 交付范围

- 用户选择现有查询快照或上传 CSV / TSV 数据，描述图种、坐标列、单位和筛选；字段或条件不明确时先询问，不猜测科学参数。
- 模型通过工具调用分别选择 `Python` 或 `Gnuplot` 引擎；支持散点、折线、直方图和误差棒，支持标题、轴标签、单位、图例、范围和显式筛选。多列叠加与缺失值需明确处理。
- 网页显示执行状态、可放大的图像、使用的数据和实际代码；可选择保存 PNG、PDF、输入数据、绘图脚本和说明清单。
- Python 生成独立 `.py` 脚本；Gnuplot 生成独立可执行的 `.plt` 脚本，数据另存为 CSV / TSV。两种引擎各自生成，不把 Gnuplot 脚本嵌入 Python 或 Notebook 当作替代。
- 绘图脚本由模型生成或组织后执行；系统提供明确的隔离执行边界，网页可在执行前查看代码及输入。结果与对应实际脚本、数据、参数和引擎版本绑定。

不以本版承诺任意系统命令、联网下载、访问本机任意文件、安装依赖、模型执行无限制代码、交互式任意脚本或自动科研结论。初始数据量与图形种类有明确上限；其他需求展示不支持或请求补充。

## 2. 用户流程

1. 在项目或会话中选择完整结果快照，或上传本地 CSV / TSV；显示列名、类型、缺失数量和已知单位。上传文件须保存为独立输入副本，原文件不被覆盖。
2. 自然语言输入绘图需求，选择自动、Python 或 Gnuplot。自动模式由模型选择，并在生成方案中显示实际引擎；用户指定引擎时不得静默更换。
3. 模型输出绘图计划和可执行脚本，页面显示数据来源、列、单位、筛选、图种、引擎、代码和预期输出。系统校验后调用对应工具；涉及上传数据或查询结果的上下文按已有模型服务隐私规则清楚展示。
4. 在隔离环境执行，显示排队/运行/成功/失败及实际错误；执行完成后网页直接预览 PNG，可放大并切换图像，保留此前结果。
5. 用户按需勾选并下载 PNG、PDF、数据、`.py` / `.plt`、说明或 ZIP。单图下载和 ZIP 的对应字节须一致；切换数据、代码或参数产生新结果，不覆盖旧记录。

## 3. 工具与接口契约

计划注册 `plot_python` 和 `plot_gnuplot` 给模型；仅接收项目内已授权的 `dataset_id`、有限长度脚本/参数、固定图像格式和请求 UUID，不接收任意主机路径、网络地址或可执行文件路径。先校验用户请求及输入来源，再创建持久运行记录。模型生成的代码不是可信指令，不能改变隔离规则或授权范围。

新增项目内数据集、绘图运行、产物和下载接口：上传数据、查看列与预览、提交绘图、读取状态和产物、按用户选择生成下载包；实施时固定 OpenAPI 路径、类型、状态码及幂等键。原 `/api/v1/chat`、查询快照、`/api/v1/exports` 和既有图表契约不破坏。模型工具结果只含运行 ID、状态、图像/说明的受控引用和错误，不暴露密钥、系统路径或异常堆栈。

用户明确指定绘图时，模型工具调用预算、单次执行时间、数据/文件/输出数量及大小均受限制；请求超额明确失败。相同请求键重放不重复执行；浏览器断线不代表任务取消，重启后运行中标为中断，不自动重跑。独立查询失败时保留成功数据和错误，不能画出虚构点或声称来自数据库。

## 4. 引擎、隔离与资源

Python 使用隔离环境和固定依赖，脚本使用实际提供的数据文件，图形采用非交互后端；Gnuplot 使用独立 `gnuplot` 程序运行 `.plt`，固定 PNG / PDF 终端输出并保存脚本与数据。安装说明在实现时记录支持版本与 Windows / Linux 启动命令；不可把用户环境中未验证的程序当作已安装。

模型生成代码属于不可信内容。执行必须由独立低权限隔离进程/容器承载，默认无网络、无凭证、无用户目录访问，仅挂载本次只读输入和临时输出；限制 CPU、内存、进程数、文件数、磁盘、输出、运行时间并可终止子进程树。Python 的语言级限制或 Gnuplot 命令过滤不能单独证明隔离安全；需在各支持平台验证操作系统级隔离。无法提供隔离的平台明确禁用执行，仍可展示计划/代码，不退回宿主机直接运行。

用户选择保存的是明确产物，通过浏览器下载或现有项目产物保存接口操作；模型不能自行选择或覆盖用户任意路径。绘图执行不连接模型、科研数据源或数据库，所有输入由服务端固定复制。限制值在实现前按可用资源、平台和验收结果写入配置与 OpenAPI，不以未验证的默认值冒充实测。

## 5. 数据、科学与可复现性

对 Gaia 使用完整实际交付行而非模型裁剪视图；标注数据发布版、查询条件、单位、样本数、截断及未参与绘图的行与原因。负视差是测量值；`pmra` 已含 cos(dec)，不得重复修正；观测颜色—星等图使用视星等且未自动消光校正。位置候选源不等同星团成员，不自动推断年龄、质量或距离。

上传数据保留原文、编码、分隔符、列名、缺失与单位；长编号保留字符串，不用浮点表示。用户未提供单位则标为未提供；非法数值或绘图不足显示原因。文本字段安全转义，不能把 CSV 数据、Gnuplot 字符串或文献摘要中的内容当命令执行。

保存包至少包括实际执行脚本、实际输入数据、图像、README 和清单：引擎与依赖版本、运行时间、输入来源/哈希、脚本哈希、参数、数据行数、筛选与排除原因、文件哈希及警告。用户可下载单文件或选定文件 ZIP；不承诺跨系统图像逐字节相同，但参数、使用数据和计算过程应可复核。用户上传数据真实性未经验证，哈希不等于科研来源认证。
